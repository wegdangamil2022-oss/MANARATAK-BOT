# مهام التنفيذ من MASTER

- [x] إغلاق نطاق الأزرار والرجوع والصفحات محليًا حسب توجيه المالك الأحدث، مع فحص رجوع المداخل الـ253 على JSON وSQLite. تجربة Telegram مؤجلة إلى ما بعد المرحلة الثالثة؛ تفاصيل الوظائف غير المنفذة تبقى في سجلها ولا تُعد جاهزة.

- [x] سجل آلي كامل لـ703 متطلبات و50 مجموعة تفاصيل، مع منع التكرار والإسقاط وتحديد الأقسام.
- [x] محرك قواعد كلمات وروابط وأنواع رسائل مع وضع مراقبة واستثناءات واختبارات إيجابيات كاذبة.
- [x] تخزين السياسات لكل مجموعة مع صلاحيات ونسخ وتدقيق، وواجهة تعديل واختبار الكلمات والعبارات ومراقبة النص الوارد دون عقوبة.
- [x] واجهات قواعد الروابط والأنواع والسماح بالنطاقات والعبارات مع تأكيد الإزالة واختبار الحدود.
- [x] استقبال الوسائط وشروحها والتعديلات والتوجيه البشري للمراقبة دون تنزيل أو تنفيذ أوامر من المحتوى.
- [x] إعدادات وعداد نافذة الفلود لكل عضو ومجموعة، ومراقبة دون عقوبة على JSON وSQLite.
- [x] صيانة نوافذ الفلود عند الخمول وبدء التشغيل مع انتظار التنظيف الجاري عند الإيقاف.
- [ ] استكمال التدرج الأوسع ورصد انضمامات AntiRaid والاستثناءات الدقيقة وحوكمة الشبكات وفق MASTER.
- [x] تدرج اختياري من عدد تحذيرات نشطة خلال نافذة مضبوطة إلى كتم لدقيقة، مع شاهد العدد والمدة عند آخر حد.
- [x] AntiRaid لمعدل الإرسال الجماعي بقفل مؤقت ولقطة أصلية وعامل استعادة مشروط، دون حظر جماعي أو استبدال معاينة بشرية.
- [x] وضع ليلي يومي بإزاحة UTC ثابتة، وموعد استعادة مطلق ومفتاح نافذة محفوظ يمنع التكرار بعد إعادة التشغيل.
- [x] ربط اختياري لخادم المرحلة الثالثة والمؤقتات، يرفض خلط المحاكاة بالسجل الرسمي ويحترم STOP ولا يشغل نفسه افتراضيًا.
- [x] طلبات اعتراض خاصة مع تأكيد وحالات وصفحات وحدود تكرار، ومراجعة مستقلة لا ترفع العقوبة تلقائيًا.
- [x] منفذ DELETE محلي لرسالة مطابقة مرصودة موثوقة فقط، مع وسم يمنع استئناف العامل العام بلا شاهد سياسة؛ لا حقن حي أو جامع بيانات مفترض.
- [x] منفذ تنفيذ محلي اختياري لقواعد المراجعة والتحذير والكتم لدقيقة، مع تأكيد تفعيل مستقل ومطالبة تمنع التكرار وشاهد سياسة حتى الإرسال؛ أضيفت شرائح DELETE المشروط بالفهرس والتدرج والربط الاختياري لاحقًا، مع بقاء جمع البيانات الحي ضمن النواقص.
- [x] استثناءات مؤقتة محلية لفحص المحتوى والفلود من دقيقة إلى يوم، مع انتهاء دقيق وقائمة وصفحات وإزالة مؤكدة ورفض التكرار والواجهة القديمة؛ لا فتح عقوبات أو منح صلاحيات.
- [ ] إكمال واجهات المرحلة الثانية لكل وظيفة مبرمجة، دون اعتبار بقية الأوصاف وظائف جاهزة.
- [x] تنفيذ نواة تحرير مسودات الاستوديو مع الصفوف والأهداف والأنماط والمتغيرات والتاريخ والإصدارات والمعاينة الخاصة والتأكيد الدائم؛ التفاصيل والنشر والردود والوسائط ما زالت مفتوحة وفق وثيقة الشريحة.
- [x] نقل مراجعة FAQ إلى مسار شفاف كامل للقائمة والتفاصيل وصفحات الإجابة ومعاينة الاعتماد والأرشفة والتأكيد الدائم، مع بقاء متطلبات قسم التعليم الأخرى مفتوحة.
- [x] نقل عرض المكتبة وأرشفة مواردها إلى قائمة شفافة وصفحات وتفاصيل ومعاينة وتأكيد دائم لمرة واحدة، مع رفض النسخ القديمة وحفظ صفحة الرجوع الصالحة.
- [ ] إكمال العقوبات والمدد وفك القيود والقفل والفتح وإعادة الأذونات الآمنة.
- [x] استعادة عضو بقرار خاص للمالك من مصدر محول رسمي حديث وسبب يدوي منفرد، مع حفظ السبب حتى نجاح الفحص اللاحق وحجر الغموض؛ لا استعادة تلقائية ولا تجاوز للسجلات القديمة أو القيود المستقلة.
- [x] طرد مستقل بمراجعة خاصة وسجل الإشراف نفسه وحدود المعدل، دون حظر دائم، مع رفض القيود القائمة وفحص مغادرة العضو ومنع إعادة النتيجة المجهولة.
- [x] بدء المرحلة الثالثة بمساري unban/unmute المحليين لإزالة السبب اليدوي المطابق فقط، مع حفظ القيود المستقلة وفحص النوع الذري ومنع التكرار والغموض. فك القيود الحي واستعادة الأذونات يظلان ضمن المهمة الواسعة المفتوحة أعلاه.
- [ ] إكمال الترحيب والوداع والقوانين والردود والهمسات والبلاغات والتثبيت.
- [ ] إكمال إنشاء الحملات والجدولة والتسليم وإدارة القنوات والتصحيحات.
- [ ] إكمال الألعاب والمسابقات والتصويت والنقاط والنتائج والاعتراضات.
- [ ] مراجعة كل مطلب في السجل بأدلة الشفرة والاختبارات والواجهة قبل إغلاق نطاقه.

كل مهمة واسعة أعلاه عنوان حزمة، وتُقسم عند بدء تنفيذها إلى مسارات صغيرة. المهام ليست إقرارًا بأن الخدمات منفذة. تبدأ التجربة الحية بعد تجهيز البيئة وفق قرار المالك؛ المرحلة الخامسة مستثناة.

- [x] حدود قابلة للضبط للمنشن والوسوم وطول النص، ومطابقة كاملة أو جزئية للكلمات من المحرر؛ تبدأ القواعد الجديدة معطلة.
- [x] بلاغ بالرد المباشر وسجل خاص وصندوق مراجعة مخول وإغلاق مؤكد، مع حدود تكرار ودون حفظ المحتوى.
- [x] إعداد تنبيهات البلاغات الاختيارية لكل مشرف ومجموعة، مع زر رجوع وطابور محمي من تكرار النتيجة المجهولة واختبارات إرسال وهمي؛ تجربة Telegram الحقيقية مؤجلة.
- [x] إعادة فحص تنبيهات البلاغات بعد انتظار بوابة الإرسال: سحب التفويض أو إيقاف التنبيه أو إغلاق البلاغ أو تغيير إيصال المحاولة يمنع الإرسال والتكرار، مع 18 حالة تزامن على JSON وSQLite.
- [x] واجهة تنظيف مفلتر للمالك عبر 02:13: مجموعة ومرسل ونوع وفترة وعدد، ومعاينة واعتماد وتنفيذ منفصل لكل رسالة وإلغاء واستئناف ورجوع، عبر خدمة الحذف الحالية؛ جامع البيانات والربط الحي والتنظيف الخدمي المؤجل مفتوحة.
- [x] قوانين مرقمة بإصدارات واعتماد خاص وإلغاء المعاينة بالرجوع، وربط /warnrule بالفقرة والإصدار والرسالة الأصلية مع إبقاء تفسير التحذير القديم.
- [ ] استكمال عقوبات الفقرات واستثناءاتها المفصلة وتقاريرها وفق RULELAW.

- [x] تكرار النص المطبع لنفس العضو داخل نافذة الفلود بحد اختياري وبصمات دون نص صريح، مع منع التنفيذ بعد انتهاء الدليل؛ الربط الشبكي والتشابه الدلالي مفتوحان.

- [x] رصد دفعات الانضمام من رسائل الخدمة البشرية الصحيحة، بإعداد مستقل معطل وحدود وعد فريد وبصمات، وقفل مؤقت واستعادة اللقطة دون حظر الأعضاء؛ لا ادعاء بتغطية الانضمامات غير المرصودة.

- [x] اشتراك إجباري بقرار مالك مستقل ومصدر حديث ومنفذ رسمي، وفك علة اشتراك منفردة مطابقة مع حفظ السبب حتى النجاح؛ لا فتح للقيود المستقلة أو الغموض.
- [x] تحقق شخصي خاص مع تقدم وروابط جهات موثوقة وإعادة تحقق، ونطاق إرسال مستقل عن الموارد يعيد فحص عضوية المجموعة.
- [ ] استكمال الفحص الدوري ومهل المغادرة والتنظيف الآلي لرسائل الاشتراك وفق GATE.

- [x] قاعدة اختيارية معطلة لمراجعة النطاقات التي تشبه نطاقًا رسميًا يحدده المشرف، مع اختبار الروابط المخفية والواجهة؛ الكشف محدود ولا يثبت الاحتيال.

- [ ] استكمال الاحتيال وانتحال الهوية والحسابات والروابط المزيفة وفق SPAM-007.
