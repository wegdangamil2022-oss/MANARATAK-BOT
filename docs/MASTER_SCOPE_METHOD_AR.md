# مرجع النطاق: MASTER الكامل للمراحل 1–4

بتوجيه المالك، لا يُستخدم عدد الأزرار المختصرة لإثبات اكتمال البوت. الأزرار الـ253 حاويات واجهة معتمدة؛ قد تتطلب الوظيفة عدة شاشات وأزرار داخلية، وبعض متطلبات MASTER ضوابط خلفية لا تحتاج زرًا أصلًا.

## الملفات

- `MASTER_REQUIREMENTS_1_4.json`: جميع المتطلبات الـ691 الأصلية والامتدادات الـ12، النص الأصلي والسطر والوحدة والقسم وحالة تقييم التنفيذ، وضوابط S12 الـ32 وS121 الـ18، وحالات القبول T12/T121 الـ48، ومواقع الأقسام السردية في المصدر.
- `MASTER_REQUIREMENTS_1_4_AR.md`: قائمة مراجعة لكل متطلب بحسب وحدته.
- `MASTER_SECTIONS_1_4_AR.md`: توزيع المتطلبات على أقسام المالك الـ16؛ ما يخص قسمين يظهر فيهما بالمعرف نفسه ولا يُعد مطلبًا جديدًا.
- `tasks/plan.md` و`tasks/todo.md`: العمل الجاري؛ لا تُستبدل المهمة بتصميم أو وصف زر.

التوزيع على المراحل والأقسام **تخصيص هندسي وفق مقدمة الخطة الحالية**، وليس جدولًا رسميًا جديدًا لترقيم كل معرف. حُفظت المطالب المتداخلة بدل إسقاطها: فمثلًا ضبط صلاحيات المساعد وعزله مطلوب للنواة الحالية، بينما خدمة التوليد نفسها مؤجلة. ربط API مستثنى صراحةً، وMini App يبقى في النهاية. 690 مطلبًا مرشحًا للعمل في المراحل الأربع وفق هذا التخصيص؛ 13 مؤجلة ببيان سببها. لا تعني هذه الأعداد اعتمادًا بإغلاق متطلب أو إضافة نسخ متعددة له.

النصوص السردية، ومنها استيراد ملف وجدولة 200 منشور ومهلة النشر ومعيار الفصل بين المحاكاة والتجربة الحية، تبقى في MASTER، ويُثبت السجل بصمة SHA256 للملف كاملًا ومواقع أقسامه. تفاصيل S12/S121 وحالات القبول لا تعاد إضافتها إلى العدد 703.

## منع الادعاء الزائد

وجود اسم ملف أو زر لا يثبت استيفاء كل المعايير. لذلك:

- NOT_ASSESSED: تغطية المتطلب لم تُحسم بعد؛ لا يُفترض أنه مكتمل أو أنه غائب بالكامل.
- PARTIAL_LOCAL: توجد شريحة شفرة واختبارات محددة وحدود موثقة؛ لا تعني تنفيذ كل النص أو ربطه حيًا.
- لا يوجد متطلب موسوم مكتملًا بهذا الجرد؛ لا يجوز تحويل مرور فحص الكتالوج إلى «كل الوظائف مبرمجة».

## فحص السجل

```bash
npm run audit:master
# فقط بعد تعديل متعمد للمصدر أو التخصيص ومراجعته:
npm run audit:master -- --write
```

يتحقق الفحص من 73 وحدة وعدّ كل وحدة وتفرد المعرفات، ومن 691+12 متطلبًا و50 تعريف تفصيل و48 حالة قبول. يرفض اختلاف ملف JSON المحفوظ عن المصدر أو سياسة التخصيص الحالية. تُراجع التغييرات ويعاد التوليد صراحةً؛ لا يسقط فحصٌ بندًا جديدًا أو يعيد تسميته تلقائيًا لتمرير النجاح.

فحص أزرار المرحلة الأولى ما زال مفيدًا للتنقل والصلاحيات، لكنه لا يغني عن هذا السجل ولا عن تنفيذ واختبار وظائف المطالب.
