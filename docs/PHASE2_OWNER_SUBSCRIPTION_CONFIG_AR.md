# إعداد قاعدة الاشتراك من أزرار المالك

حالة 2026-11-01: ربط محلي جزئي للزرين 02 «القنوات المطلوبة» و04 «الاشتراك الإجباري» في القسم 04 الرسمي. لا يغلق هذا كامل قسم الانضمام أو المرحلة الثانية.

المسار: اختيار مجموعة معتمدة للتصفح والتحقق ← اختيار جهات التحقق المعتمدة في صفحات من ثمانية ← اختيار «جميع القنوات» أو «قناة واحدة على الأقل» ← معاينة ← تأكيد مستقل للحفظ وفحص صلاحية التحقق. تحفظ الاختيارات عند الانتقال بين الصفحات. الحد عشر جهات وفق الخدمة القائمة. يمكن معاينة تعطيل الشرط وتأكيده؛ لا حذف للاعتماد أو عقوبة أو فك كتم تلقائي. يعرض المحرر معرّفات الجهات المعتمدة، ولا يستنتج نوع Telegram الفعلي من المعرّف. لا يعرض السجلات المتعارضة أو قواعد الاشتراك المحرفة كإعداد صالح.

كل ضغطة تعيد فحص المالك والخاص واللوحة والمصدر. المرجع عشوائي محفوظ للمستخدم، صالح لدقيقتين ولمرة واحدة؛ حد المراجع 128. الإلغاء يعيد قائمة المجموعات ويلغي المراجع السابقة لهذا المسار. لا يغير اختيار القناة أو الوضع القاعدة قبل التأكيد. عند غياب خدمة التحقق تظهر حالة عدم الإتاحة بدل حفظ وهمي.

تستعمل واجهة الحفظ SubscriptionGate.configure الأصلية. أضيف معامل شاهد اختياري للخدمة يحافظ على استدعاءاتها القديمة؛ عند استعماله يجب تطابق الاعتمادات وقواعد الاشتراك وإعدادات الخاص قبل فحص المزود وداخل معاملة الحفظ. تغير أي منها أثناء الفحص يرفض الحفظ. فحوص الجهات المعتمدة المستقلة تعمل بالتوازي، بحد عشر، بدل مضاعفة مهلة المزود بالتسلسل؛ لا تحدث كتابة إلا بعد نجاحها جميعًا وإعادة فحص المصدر. يسجل الحفظ المؤكد في التدقيق.

الردود المؤجلة تحمل شاهدًا صادرًا من معاملة بناء الشاشة نفسها، ويشمل مصدر إعدادات الاشتراك ضمن حماية ردود المالك. تغير المصدر أو إلغاء اعتماد جهة قبل الإرسال يمنع عرض شاشة قديمة. لا يحمل callback معرّفات الجهات أو إعدادات الحفظ الخام.

الاختبارات على JSON وSQLite تغطي المسار الكامل والصفحات ووضع ANY، عدم التغيير قبل التأكيد، منع التكرار والإلغاء والانتهاء والنسخ إلى مستخدم أو مجموعة، رفض جهة غير قابلة للتحقق أو ملغاة، تغير الإعدادات أثناء فحص المزود، حجب الرد المؤجل، التعطيل المؤكد دون استدعاء المزود، وتوازي فحوص الصلاحيات قبل الحفظ. لا شبكة حقيقية أو كتابة إلى قاعدة أصلية.

الحدود: لا حد أدنى عددي مثل اثنتين من خمس؛ الخدمة الحالية تدعم ALL/ANY فقط. لا إنشاء اعتماد أو مجلد مجتمع أو روابط دعوة، ولا فحص نوع الجهة بـgetChat أو حقوق Telegram خارج تحقق الخدمة القائمة، ولا تجربة حية في هذه الدفعة. فتح سجل محفوظ متعارض يحتاج إصلاح سلامته من المسار المعتمد، ولا يتجاوزه هذا المحرر. القبول المرئي والوظائف الأوسع لقسم الاشتراك تبقى مفتوحة.

مغادرة المحرر إلى وظيفة أخرى تلغي مراجع التأكيد التي لم تبدأ وتغلق شاهد جلسة العرض. لكل شاشة جديدة شاهد عرض مستقل؛ لذلك يحجب الطابور أيضًا معاينة قديمة بعد المغادرة حتى لو لم تتغير قاعدة الاشتراك. يشمل الاختبار الرجوع للوحة المالك ثم محاولة استعمال التأكيد القديم وإرسال معاينته. لا يلغي الرجوع عملية حفظ سبق قبول تأكيدها وبدء فحصها.
