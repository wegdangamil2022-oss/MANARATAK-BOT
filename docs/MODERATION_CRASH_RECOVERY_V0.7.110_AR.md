# v0.7.110 — حماية تقرير استعادة الإشراف بعد تعطل البوت

## لماذا تغيرت حالة الاستعادة؟

كانت الأداة المحلية `telegram:moderation-recovery` (قراءة فقط) تصنف `INTENT` و`STARTED` الحديثتين كحالة `OK` إذا لم يمر حد التقادم. ولكن بعد توقف الخادم أو إعادة تشغيله، لا يستطيع الفحص المنفصل معرفة هل العملية القديمة ما زالت قيد المعالجة أم انقطع تنفيذها. كما أن `STARTED` لا يثبت نجاح إرسال العقوبة أو فشلها.

لذلك أصبح التقرير يُظهر **`ATTENTION_REQUIRED` لأي سجل غير محسوم**:

- `INTENT`: قد يكون الحجز معلقًا بعد توقف العملية، ولا يعد دليلاً على عدم إرسال طلب Telegram.
- `STARTED`: ربما خرج الطلب وربما لم يخرج، ولا يمكن الجزم من الزمن وحده.
- `UNKNOWN_OUTCOME`: يحتاج مراجعة بشرية حتى عند وجود إقرار مراجعة سابق؛ الإقرار لا يحل الغموض.

تحتفظ الحقول `staleIntent` و`staleStarted` بمعناها: **عمر الحالة** قياسًا بالوقت المحدد، لا إثبات وقوع إرسال أو تأخر Telegram. أصبح `manualAttention` عدد **كل** العمليات غير المحسومة، وليس القديمة منها فقط.

## بعد إعادة التشغيل

1. أبقِ عقوبات Telegram الحية معطلة ومفتاح المشغّل في وضع `STOP`.
2. افحص قاعدة SQLite باستخدام أمر التقرير المعتمد داخل بيئة الخادم المحلية فقط. لا ترسل قاعدة البيانات أو التوكنات في المحادثات.
3. إذا خرج أمر التقرير بالحالة `ATTENTION_REQUIRED` ورمز خروج **2**، راجع السجلات المقيدة عبر واجهة المالك أو أدوات التشغيل الموثوقة، ولا تعِد إرسال عقوبة مجهولة النتيجة.
4. لا تُحوّل `STARTED` تلقائيًا إلى `CONFIRMED` أو `CANCELLED`، ولا تمسح سجل الأثر لإخفاء التحذير.

## حدود الإصدار واختبارات التحقق

- اختبارات الوحدة تكشف أن `INTENT` و`STARTED` الحديثتين كانتا تظهران `OK` خطأً.
- اختبارات SQLite تؤكد أن الفحص لا يكتب في قاعدة البيانات؛ واختبار CLI يؤكد رمز الخروج **2** دون تسريب بيانات المجموعة أو بصمة السبب أو التوكن.
- اختبار إعادة تشغيل فعلي للمخزن في JSON وSQLite يؤكد منع إعادة إرسال `STARTED` غير المحسومة.
- لا اتصالات Telegram فعلية، ولا إعادة محاولة تلقائية، ولا تفعيل للحظر أو الكتم.

**تنبيه:** قد يظهر التحذير أثناء عملية جارية بشكل طبيعي لأن التقرير المحلي لا يمتلك إثبات حياة للعامل التنفيذي. هذا مقصود لتجنب نتيجة `OK` مضللة بعد التعطل؛ هو تنبيه للمراجعة وليس حكمًا بأن العقوبة نُفذت.
