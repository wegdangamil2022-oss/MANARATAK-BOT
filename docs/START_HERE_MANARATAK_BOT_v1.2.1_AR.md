## التكليف الجاهز للنموذج المبرمج

أنت مسؤول عن تنفيذ MANARATAK BOT في مشروع مستقل. اقرأ MASTER v1.2.1، وخصوصًا الأقسام1 و2 و11–16 ثم كتالوج المتطلبات بالقسم17. ابدأ الآن B0 ثم B1 فقط محليًا وبالمحاكاة، ولا تكتف بخطة. افحص AGENTS.md وواقع الملفات وحالة git؛ لا تستبدل عمل المستخدم ولا تعتبر لقطة المستودع القديمة حالته الحالية.

نفذ نواة TypeScript بهوية مالك موثوقة، وقائمة سماح وتصاريح منفصلة عن وجود البوت، وdefault-deny، وتفويض داخلي محدود بلا تصعيد، ومغادرة وتعاف وتدقيق ومنع تكرار قابل للاسترداد. سياسات منشن المجموعة وAI الخاص ومفاتيح التعليم والتحقق ولوحة المالك مستقلة؛ تظل AI غير جاهزة ومغلقة قبل التهيئة.

ضمن B1 بأبسط تنفيذ واختبارات:

1. **UpdatePipeline — S121-01:** بوابات حسب نوع الحدث؛ غير المعتمد لا يدخل تنزيلًا أو فهرسة أو AI. مسار تحقق الاشتراك لا يمنعه شرط الاشتراك نفسه. سجل النية قبل الأثر ونتيجته بعده، ولا تضع DONE مبكرًا.
2. **CallbackActionCodec — S121-02:** مرجع قصير لا يحمل أسرارًا؛ تحقق خادمي من الضاغط والنطاق والنسخة والانتهاء. ميّز زر الإدارة من الزر العام لكل طالب؛ إقرار callback لا يثبت نجاح العملية.
3. **OutboundPriorityPolicy — S121-03:** P0 للحماية وP1 للتفاعل وP2 للحملات، مع عدالة واحترام الانتظار وإعادة المحاولة. fake clock يكفي في B1؛ لا وعد فورية أو Redis إلزامي.
4. **WizardSessionStore — S121-04:** جلسة معزولة بالهوية والمحادثة والموضوع والمسار عند الحاجة، وانتهاء وإلغاء ورجوع ومنع انتقال مزدوج؛ عقد ومعالج اختبار صغير، لا نظام رفع ونشر كامل.

- Ephemeral مسار فعلي مشروط؛ لا تختزل إلى تنبيه200 حرف أو تفترض فتح Mini App تلقائيًا. البديل يحترم إغلاق الخاص ولا يكشف المحتوى علنًا.

- المعاينة الكبيرة خيار عرض ببديل معتمد، لا ضمان ظهور أي صورة.
- UNKNOWN_OUTCOME تبقى مجهولة حتى دليل فريد أو قرار مراجعة موثق؛ بصمة نص متكرر لا تكفي.
- تمرير آخر منشور جامعة يثبت مرشحه فقط؛ لا يجعل كل السابق PUBLISHED_VERIFIED. التجاوز اليدوي MANUALLY_SKIPPED مستقل.
- FAQ لا يتجاوز إعداد المنشن أو إغلاق الخاص، ولا يحجز ميزانية توليد عند الرد المعتمد.
