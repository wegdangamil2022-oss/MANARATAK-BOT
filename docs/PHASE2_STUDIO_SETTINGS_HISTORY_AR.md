# سجل إعدادات الاستوديو واستعادتها

من «⚙️ إعدادات الاستوديو» في القسم 07، يفتح «📜 سجل الإعدادات واستعادتها» التغييرات الموثقة في صفحات من ثمانية عناصر. اختيار عنصر يعرض القيم الحالية والقيم السابقة المقترحة، ورقم التعديل وصاحبه وتاريخه، ثم تأكيدًا مستقلًا أو إلغاءً يبطل هذا التأكيد فقط.

يشمل السجل الإعدادات المحلية الستة: القالب الافتراضي، حد الأزرار، عدد صفوف الصفحة الجديدة، الألوان الوظيفية، مدة الإدخال، ومدة التأكيد. كل تغيير جديد يحفظ قيم ما قبله وما بعده مع دليل تدقيق مطابق لبصمتها. لا نُنشئ قيمًا سابقة للتغييرات التي سبقت إضافة هذا السجل؛ تظهر حالتها الفارغة بوضوح. بقاء الدليل شرط لعرضه واستعادته.

الاستعادة تحفظ القيم السابقة بإصدار إعدادات جديد، وتضيف تغييرًا موثقًا يمكن التراجع عنه بالطريقة نفسها، دون تعديل القوالب أو نسخها المحفوظة أو حذف التاريخ. لا يمكن استعادة حد أزرار يقل عن أي مسودة موجودة، أو قالب افتراضي غير موجود أو مكرر.

يفحص الخادم المالك وإتاحة لوحته، وفرادة المرجع ودليل التدقيق وبصمته، وإصدار الإعدادات والقيم السابقة. التأكيد خاص بالمالك ومدته مدة التأكيد الحالية (30–120 ثانية) ولمرة واحدة. يرتبط أيضًا بالقوالب الحالية: تغيير إعداد أو قالب بعد المعاينة يمنع التنفيذ بدل تطبيق معاينة قديمة. تُستهلك الموافقة ويُحفظ الإعداد ودليله الجديد في معاملة واحدة؛ الإلغاء لا يبطل موافقات مستقلة.

شاشتا السجل ومعاينة الاستعادة تحملان شاهد حداثة الاستوديو قبل تجهيز الرد وعند إرساله. تغير الإعدادات أو القوالب أو أدلة السجل، أو سحب إتاحة اللوحة، يحجب الرد المؤجل. لا يمنح شاهد العرض صلاحية التنفيذ؛ التأكيد يعيد فحص شروطه.

الدليل في `tests/studio-settings-history.test.ts` على JSON وSQLite: إعادة فتح التخزين، استعادة جميع الحقول، التراجع عن الاستعادة، التزامن والتكرار، الإلغاء وانتهاء المهلة، حدود الأزرار والقالب المفقود، تغير القوالب أو الإعدادات، حجب المالك الآخر وسياق المجموعة، الأدلة المعدلة أو المكررة أو المستقبلية، صفحات السجل وحجب الرد القديم. يشمل التحقق أيضًا اختبارات الاستوديو والإلغاء وحداثة المعاينات السابقة.

هذا تقدم محلي لـUX-004 وUX-008؛ لا يغلق استعادة بقية إعدادات البوت أو النسخ الاحتياطية أو متطلبات النشر والحقوق الحية. لم تُضف هجرة تخزين أو طلبات Telegram أو بيانات اختبار إلى مخزن تشغيل أصلي.
