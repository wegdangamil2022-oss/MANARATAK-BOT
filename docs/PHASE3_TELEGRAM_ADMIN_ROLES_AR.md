# إدارة مشرفي Telegram — IAM-004 وIAM-005

المسار المحلي: لوحة المالك ← قسم المشرفين ← صلاحيات Telegram ← المجموعة ← إدارة مشرف Telegram. يُطلب المعرف الرقمي في الخاص، ثم اختيار الإجراء، ثم معاينة وتأكيد مستقلان. الرجوع يلغي الطلب. المهلة دقيقتان من بدء الطلب.

الإجراءات المنفذة: ترقية عضو بشري بصلاحية حذف الرسائل أو تقييد الأعضاء، أو عزل مشرف يصرح Telegram بإمكانية تعديله. الترقية تتضمن صلاحية إدارة المحادثة الضمنية وتوضحها شاشة الاختيار. لا تُمنح صلاحية ترقية مشرفين، ولا تتغير التفويضات الداخلية. التنفيذ مقصور على مالك المنظومة ومجموعة معتمدة للإشراف، ولا يقبل استهداف المالك أو البوت أو مالك المجموعة أو مشرف غير قابل للتعديل.

يعيد المنفذ قراءة نوع المجموعة، وهوية البوت وحق إدارة المشرفين والحق المطلوب، وهوية العضو ورتبته قبل الإرسال. تغير مصدر التفويض أو حالة العضو أو الإيقاف أو انتهاء المهلة يمنع العملية. تُرسل جميع أعلام الصلاحيات بقيم صريحة؛ العزل يرسلها جميعًا بالقيمة false. لا يعد رد true وحده نجاحًا؛ تُقرأ حالة العضو وحقوقه بعده. اختلاف النتيجة أو انقطاع الرد يبقى غير محسوم.

تُحجز المحاولة في سجل دائم قبل أي تغيير خارجي، مرتبطة بالمالك والمجموعة والعضو والإجراء ومعرف عشوائي. التأكيد المتكرر أو المتزامن لا يعيد الإرسال. محاولة STARTED أو UNKNOWN_OUTCOME تمنع طلبًا جديدًا للعضو نفسه حتى المراجعة البشرية؛ لا يوجد فتح تلقائي لهذا المنع. إعادة التشغيل لا تمحو السجل. هذا المنع قد يحتاج إجراء مراجعة مستقلًا لاستئناف الإدارة بعد فحص يدوي؛ لا يُدعى أن واجهة تسوية الحالات الغامضة مكتملة.

الاختبارات: بوابة Telegram بمحاكاة HTTP؛ مسار الأزرار والإدخال والتأكيد والرجوع في معالج التحديثات؛ تخزين JSON وSQLite؛ الإيقاف وسحب المجموعة وانتهاء المهلة وتكرار التأكيد وإعادة فتح الحالة بعد نتيجة غامضة؛ رفض الجلسات المحفوظة المشوهة؛ وعزل العضو بعد ترقية مؤكدة بتأكيد مستقل. اجتاز المسار النهائي مع فحص الحقوق السابق 39 اختبارًا محليًا. ملف الفحص: artifacts/section-closure/admin-roles-focused-tests.log.
