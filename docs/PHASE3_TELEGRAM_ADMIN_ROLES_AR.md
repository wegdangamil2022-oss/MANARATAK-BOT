الإجراءات المنفذة: ترقية عضو بشري بصلاحية حذف الرسائل أو تقييد الأعضاء، أو عزل مشرف يصرح Telegram بإمكانية تعديله. الترقية تتضمن صلاحية إدارة المحادثة الضمنية وتوضحها شاشة الاختيار. لا تُمنح صلاحية ترقية مشرفين، ولا تتغير التفويضات الداخلية. التنفيذ مقصور على مالك المنظومة ومجموعة معتمدة للإشراف، ولا يقبل استهداف المالك أو البوت أو مالك المجموعة أو مشرف غير قابل للتعديل.

يعيد المنفذ قراءة نوع المجموعة، وهوية البوت وحق إدارة المشرفين والحق المطلوب، وهوية العضو ورتبته قبل الإرسال. تغير مصدر التفويض أو حالة العضو أو الإيقاف أو انتهاء المهلة يمنع العملية. تُرسل جميع أعلام الصلاحيات بقيم صريحة؛ العزل يرسلها جميعًا بالقيمة false. لا يعد رد true وحده نجاحًا؛ تُقرأ حالة العضو وحقوقه بعده. اختلاف النتيجة أو انقطاع الرد يبقى غير محسوم.

تُحجز المحاولة في سجل دائم قبل أي تغيير خارجي، مرتبطة بالمالك والمجموعة والعضو والإجراء ومعرف عشوائي. التأكيد المتكرر أو المتزامن لا يعيد الإرسال. محاولة STARTED أو UNKNOWN_OUTCOME تمنع طلبًا جديدًا للعضو نفسه حتى المراجعة البشرية؛ لا يوجد فتح تلقائي لهذا المنع. إعادة التشغيل لا تمحو السجل. تتوفر الآن واجهة «مراجعة المحاولات» من شاشة صلاحيات المجموعة: قائمة بصفحات محدودة، وقراءة الحالة الحالية، وإقرار الاطلاع أو تسجيل الحاجة إلى تدخل بشري. يسجل القرار مرة واحدة بدليل مرتبط بالمحاولة والقراءة ومصدر التفويض، دون تغيير نتيجة المحاولة الأصلية أو فتح إعادة الإرسال. لا تثبت قراءة الحالة الحالية هوية من تسبب فيها. الرجوع أو بدء طلب آخر يلغي تأكيد المراجعة، وتأخر القراءة لا يعيد تفعيلها. تسجيل الحاجة إلى تدخل بشري محلي فقط ولا يرسل رسائل خارجية.
