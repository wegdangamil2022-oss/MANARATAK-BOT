# تصفح مكتبة المجموعة بالأزرار الشفافة

يفتح `/categories` في مجموعة مخولة بالتصفح قائمة أقسامها، ويفتح `/resources <category>` موارد القسم. تعرض القوائم ثمانية عناصر في الصفحة، مع التالي والسابق وتفاصيل المورد والرجوع إلى صفحة القسم وصفحة الأقسام نفسها. الأزرار تستخدم callbacks وتعديل الرسالة، وليست أزرارًا ترسل نص «رجوع».

كل مرجع تنقل عشوائي محفوظ خادميًا، مرتبط بالمجموعة وبصاحب الطلب وببصمة اعتمادها والاشتراك ومحتواها، وصالح لدقيقتين. تحفظ حتى 128 إشارة تنقل فعالة لكل مستخدم ومجموعة. تُرفض المراجع المكررة والمنتهية والملغاة والمنسوخة إلى مستخدم أو مجموعة أو خاص آخر. فحص قنوات الاشتراك النشط يتكرر عند كل طلب وضغطة، ولا تُقبل نتيجة NOT_REQUIRED بديلًا عن عضوية مطلوبة. تغير السياسة خلال الفحص يمنع العرض.

تظهر الأقسام ذات السلسلة السليمة والمفعلة في نطاق المجموعة، والموارد المنشورة الفريدة فقط، دون معرفات الاستيراد أو مراجع المصدر الداخلية أو هوية المراجع. لا يملأ محتوى الخاص مكتبة المجموعة. ردود القوائم والتعديل تحمل شاهد المجموعة القائم، وتُعاد مراجعتها قبل الإرسال، بما يشمل سحب المورد أو القسم أو اعتماد المجموعة أو تغير الاشتراك.

الدليل: `tests/group-library-inline.test.ts` مع اختبارات الاشتراك، ولوحة الطالب القديمة، والاستيراد عبر وسائل النقل، وطابور التصفح الخاص للمجموعات. التنفيذ محلي، ولا يرسل إلى Telegram أثناء الاختبارات. لا تُفعّل عقوبات أو نشر أو توسيع صلاحية مجموعة. تدعم مكتبة المجموعة الآن سياسات ظهور مستقلة للعامة ولكل موضوع، مع الربط بالوجهة ومنع نقل المرجع بينها؛ تفاصيل الإدارة والافتراضات والحدود في `PHASE2_CATEGORY_CONTEXT_VISIBILITY_AR.md`. تبقى مراجعة سائر المداخل والتجربة الحية والمراجعة الشاملة مفتوحة.
