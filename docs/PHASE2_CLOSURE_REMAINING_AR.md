## ترتيب الاستكمال

1. استكمال نقل الوظائف المبرمجة المتبقية إلى أزرارها المعتمدة، ومنها التصنيفات والإعدادات والتفويضات، دون نسخ منطق الصلاحيات خارج الخدمات.
2. استكمال معالج المجموعة ومراجعة حالة الحقوق والإعدادات وسجل النسخ والاسترجاع.
3. تنفيذ محرر الرسائل والأزرار والصفوف والقوالب والروابط والإصدارات والشروط حسب التفاصيل الرسمية.
4. استكمال المسارات الأخرى التي تتطلبها متطلبات المرحلة، وجرد الفجوات لكل مدخل بدل إغلاقها من اسمه.
5. مراجعة المتطلبات والضوابط التفصيلية المرتبطة بها، وإثبات القبول المحلي، وإبقاء التجربة الحية المؤجلة بندًا مستقلًا. لا تُعلن المرحلة مغلقة حتى تزول فجوات نطاقها المحلي.

تقدم جزئي: محرر المسودات والأزرار والصفوف والشروط المحلية، معاينة النص والأزرار، سجل جميع الإصدارات ومقارنتها واستعادتها، ونسخ القوالب ونموذجان جاهزان موثقة في PHASE2_STUDIO_DRAFT_EDITOR_AR.md. تظل شروط العضوية والأدوار والنشر والوسائط والردود التلقائية والإعدادات الشاملة مفتوحة؛ هذا لا يغلق الصفوف أعلاه.

تقدم 2026-10-30: أضيفت صفحات أزرار قابلة للتحرير مع حفظ موضع النص والرجوع، وإعدادات القالب الافتراضي وحد الكثافة والألوان الوظيفية ومدد الإدخال والتأكيد. هذه أدلة إضافية جزئية لـBUTTON-001/002/010/012 وUX-004؛ لا تغلق المسارات العامة للنشر أو صلاحيات المصممين أو متطلبات الواجهة الحية.

تقدم إضافي: تفحص قوائم الطالب والبحث ومصادر FAQ سلامة سلسلة القسم، وتُحجب الدورات أو الأقسام المتكررة عند استعادة حالة متعارضة. هذا لا يستبدل سياسات السياق الناقصة في HUBCFG-003 ولا يثبت حماية جميع الردود المؤجلة.

تقدم إضافي: ردود مكتبة الطالب الخاصة ذات الأزرار المضمنة يعاد التحقق من صلاحية التعليم ونسخة الإعدادات ومحتوى التصنيفات والموارد قبل إرسالها، وتمنع الردود المتقادمة أو المنتهية؛ اختُبر ذلك محليًا على JSON وSQLite. لا يشمل هذا الحماية العامة للردود القديمة أو كل مسارات FAQ والمجموعة، ولا يغلق HUBCFG-003 أو BUTTON-007/014.

تقدم جزئي إضافي في بطاقة «مجموعاتي»: أصبحت بطاقة المجموعة المعتمدة تعرض حالة سياسة الحماية المحفوظة ونسبة القواعد المحددة للمراقبة، مع التمييز بين «غير مضبوطة» و«متوقفة» و«مراقبة فقط» و«تحتاج مراجعة» وغياب نطاق الحماية. يتيح محرر الكلمات والعبارات عودة مقيّدة بإصدار المجموعة وصفحتها إلى بطاقتها الصحيحة، مع إعادة التحقق عند الضغط ومنع العودة عبر رابط قديم أو لمجموعة ملغاة أو متعارضة. اختُبر المسار على JSON وSQLite، بما في ذلك تعدد صفحات المجموعات. هذه قراءة محلية فقط؛ لا تثبت حقوق Telegram الحية ولا تفعّل الحذف أو الكتم، ولا تغلق UX-004 أو UX-005 بالكامل.

تقدم إضافي في المرحلة الثانية — «🔍 فحص الصلاحيات» ضمن «👥 المجموعات والشبكات»: تمت إضافة شاشة مالك للقراءة فقط تجمع النطاقات المحلية المحفوظة وحالة قواعد الحماية لكل مجموعة معتمدة، وتعرض المجموعات بثمانية عناصر لكل صفحة مع الانتقال إلى بطاقة المجموعة بإصدارها الحالي. ترتبط الشاشة من زر القسم الرسمي وكذلك من قائمة «مجموعاتي»، وتعيد فحص هوية المالك وسياق الخاص في كل انتقال. تُحجب المجموعات المعتمدة المتعارضة أو الملغاة، وتظهر السياسة ذات الإصدار القديم أو الطابع الزمني المستقبلي كـ«تحتاج مراجعة»، لا «مراقبة نشطة». تمت إضافة اختبارات للتنقل والصفحات والتفويض وسلامة الحالة على JSON وSQLite. هذه شاشة لفحص التفويضات **المحلية فقط**؛ لا تفحص الحقوق الحقيقية للبوت في Telegram ولا تثبت أن الحماية الحية تعمل. لا يغلق هذا UX-005 أو UX-007 أو قسم الفحص الحي.

تقدم 2026-10-31 — قسم «👥 المجموعات والشبكات»: استُبدلت الشاشات الوصفية للمدخلين «🔔 تنبيهات الشبكة» و«🚦 أوضاع التشغيل» بواجهتين آمنتين **للقراءة فقط من بيانات البوت المحلية**. تعرض الأولى مجموعات تحتاج مراجعة عند عدم تأكيد وجود البوت محليًا أو عدم ضبط سياسة مراقبة الحماية أو تقادم السياسة أو غياب إعداد الاشتراك في النطاق المخول أو تعارض بيانات الاشتراك أو عدم اتساق وضع المساعد. تعرض الثانية وضع سياسة الحماية والمساعد والنشر المحفوظ لكل مجموعة مع تنقل بثماني مجموعات للصفحة، وروابط بطاقة مجموعة مرتبطة بإصدارها وصفحتها الفعلية. تُحجب المجموعات الملغاة أو ذات السجلات المتعارضة، ويُرفض التصفح القديم بعد تغيير السياسة. تشمل الاختبارات JSON وSQLite، وتؤكد أن شاشات التشخيص لا تغيّر الحالة ولا تعرض تنبيهًا مرسلًا إلى Telegram ولا تنفذ عقوبة. تبقى **التنبيهات الآلية للمديرين، وفحص صلاحيات Telegram المباشر، وتشغيل الإنفاذ، وسجل تغيير الوضع مع التراجع** غير منفذة؛ لذلك لا يغلق هذا UX-003 أو UX-005 أو UX-007 ولا المرحلة الثانية عمومًا.

تقدم إضافي (قوالب المجموعات): أصبح مدخلا «📑 قوالب الإعدادات» و«🔄 نسخ ومقارنة الإعدادات» مرتبطين بواجهات مالك آمنة فعلية، مع قالب فارغ وقالب مراجعة الروابط، واختيار المجموعة، ومعاينة وفحص قواعد محلي بعينة ثابتة، وتأكيد مخزن خادميًا لمدة دقيقتين ولمرة واحدة، واختبارات على JSON وSQLite. يمكن نسخ قواعد حماية من مجموعة معتمدة إلى أخرى **إذا لم تكن للهدف سياسة قائمة**، مع عدم نسخ الاستثناءات والنطاقات المسموحة أو العقوبات، ويمكن مقارنة مجموعتين مضبوطة سياساتهما للقراءة فقط. الإجراء يحفظ `MONITOR` أو `OFF` محليًا، مع قفل عند تغير موافقة المالك أو إصدار المجموعة أو سياسة المصدر، ويدون عملية الحفظ في تدقيق ذري. المسارات موثقة في `docs/PHASE2_GROUP_POLICY_TEMPLATES_AR.md`. لا يزال اعتماد الربط الحي ومجموعات الشبكة والقوالب الشاملة والاسترجاع والمزامنة وإدارة جميع الحقوق مفتوحًا، فلا تغلق المرحلة ولا المطالب UX-003 وUX-007 وUX-008.
