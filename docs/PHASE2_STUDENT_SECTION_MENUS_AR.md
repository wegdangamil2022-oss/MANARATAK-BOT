# المرحلة الثانية — تصفح أقسام الطالب بالأزرار الشفافة

## ما نُفذ

أزرار الطالب الحالية للمنح والدورات والجامعات والاختبارات والملفات والمكتبة العامة تفتح قوائم Inline عند استخدام خادم التشغيل. بقيت الأسماء والترتيب كما هي؛ التغيير في معالج الضغطة. يعتمد التصنيف على matchingCategories نفسه الذي كانت تستخدمه القوائم النصية، ويعرض محتوى المكتبة المحلية المعتمد فقط. لا يستدعي API منصة منارتك.

كل قسم له سياق تصفح `si:2:<section>:...` مستقل. تحفظ صفحات الموارد وزر الرجوع القسم والصفحة، ويعود «🏠 المكتبة» إلى جميع أقسام المكتبة. تظل روابط `si:1` القديمة و`/studentinline` صالحة وفق صلاحياتها الحالية. التكاملات المباشرة تحتفظ بالقوائم القديمة ما لم تضبط `studentMenuMode: 'inline'`؛ خادم التشغيل يضبطها صراحةً.

## التحقق والتفويض

- يتحقق الخادم من سياق الخاص وهوية الطالب وصلاحية التعليم عند كل callback.
- يعاد احتساب الأقسام المرئية داخل القسم المختار والموارد المنشورة وبصمة الاختيار عند كل انتقال؛ تغيير الرمز في callback ليس تفويضًا.
- يحتفظ parser بالنسخة القديمة، ويرفض رموز الأقسام المجهولة والأرقام غير القياسية والزيادات والروابط الطويلة.
- تعترف حراسة InlineKeyboard بالصيغة الجديدة المحددة فقط؛ لا تسمح بأزرار URLs أو مسارات إدارية داخل هذه القوائم.
- الاختبارات تغطي الأقسام الستة، القوائم الفارغة، التفاصيل والرجوع، صفحات موارد متعددة، تعطيل التعليم أو القسم، منع سياق المجموعة، والاختيار المحرف. يستخدم اختبار خادم HTTP الحقيقي نقل Telegram وهميًا.

## الحدود

هذه برمجة واجهة المكتبة المحلية؛ لا تنشئ محتوى أو منحًا، ولا تستكمل وظائف الأقسام الإدارية الـ16. الألعاب والعقوبات والتفاعل تحتاج معالجاتها المتخصصة في المراحل التالية. نجاح الاختبارات المحلية لا يثبت التشغيل على Telegram.

## نتيجة التحقق لهذه الشريحة

نجح typecheck والبناء و2434 اختبارًا دون فشل أو تخطٍّ. تشمل الاختبارات 19 حالة موجهة لقوائم الطالب، واختبار HTTP محلي لمساري المالك والطالب. أُعيد فحص قوائم المالك الـ253 على JSON وSQLite دون تغيير بيانات الأعمال أو أي استدعاء شبكة.
