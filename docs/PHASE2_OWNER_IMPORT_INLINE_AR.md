# مراجعة الوارد بأزرار شفافة

حالة 2026-11-01: تنفيذ محلي جزئي لمطلب «📥 استيراد البيانات» في القسم 13، الزر 04، حسب وثيقة الأزرار الرسمية. لا يغلق كامل وظائف الاستيراد أو المرحلة الثانية.

المسار المتاح: صفحة الوارد ← سجل الاستيراد ← المرشح ← اختيار القسم ← معاينة الاعتماد ← تأكيد مستقل ← معاينة الإتاحة ← تأكيد النشر بالمكتبة المحلية. يعاد استخدام OwnerTelegramMenu وEducationAdminFacade والخدمات الأصلية؛ لا يوجد إرسال لقناة أو استيراد خارجي تلقائي. التصفح والصفحات وتفاصيل المرشح والتأكيدات تعدل الرسالة نفسها. تتوفر العودة للوارد وإلغاء المعاينة، ولوحة المالك والرئيسية وقسم التكاملات، ثم إدارة المكتبة بعد النشر.

مراجع oi قصيرة عشوائية مخزنة للمستخدم في الخاص، صالحة لدقيقتين ولمرة واحدة، بحد 128 مرجعًا لكل مالك. لا تحمل أوامر في callback. تُرفض المراجع المكررة أو المستهلكة أو المنسوخة أو المنتهية أو التي تغيرت مصادرها. فحص المالك واللوحة يتم عند كل طلب، وتعيد الخدمات فحص صلاحيات النطاق والقسم والحالة داخل معاملة الاعتماد أو النشر. زر إلغاء المعاينة يعيد قائمة الوارد ويلغي المراجع السابقة لهذا المسار خادميًا. النشر المحلي نفسه يمنع تكرار المورد عبر الخدمة الأصلية.

تتضمن حماية ردود الإدارة المؤجلة الآن مصادر الاستيراد والتصنيفات والموارد للمالك؛ تغييرها يحجب الردود الإدارية المنتظرة حتى إعادة فتح الشاشة، بما فيها ردود إدارة أخرى تأثرت بهذا الشاهد المحافظ. لا يُخزن المحتوى الأصلي في شاهد الإرسال؛ يستخدم تجزئة.

اختبار owner-inline-imports.test.ts يعمل على JSON وSQLite: الصفحات والمسار الكامل حتى النشر، تعديل الرسالة، طول callback، نقله لمستخدم آخر أو مجموعة، التكرار والانتهاء والإلغاء وتغير المصدر وتعطيل اللوحة، وحجب رد الوارد المؤجل بعد تعديل المصدر. لا يستعمل شبكة أو بيانات أصلية.

الحدود المتبقية: رفع الملف يظل عبر مسار Telegram الحالي /upload، وليس معالج رفع جديدًا؛ لا يضيف هذا العمل مطابقة حقول تفاعلية أو محللات إضافية أو جدولة منح أو تكامل منصة. لا يوجد قبول حي على Telegram في هذه الدفعة. لذلك يبقى مطلب الاستيراد الشامل والمرحلة الثانية مفتوحين.
