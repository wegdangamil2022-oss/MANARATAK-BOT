# NETWORK-005 — حفظ نسخ تاريخية محلية من سياسات الحماية

## الحالة والحدود

هذا جزء مستقل من المرحلة الثالثة في بوت منارتك ضمن PR #184، ويكمل شاشة «🧩 مقارنة إعدادات المجموعات» الموجودة مسبقًا. **المنفذ في شريحة الأرشفة الأصلية:** أخذ نسخة محلية بعد موافقة صريحة وسجل نسخ ومقارنة النسخة الحالية بالتاريخية. **تحديث مستقل لاحق:** أُضيفت معاينة وموافقة ثانية تتيح استرجاع إعدادات حماية محفوظة مع الحفاظ على وضع التشغيل الحالي، ومنع ENFORCE مطلقًا. راجع `PHASE3_NETWORK_POLICY_RESTORE_AR.md`.

يظهر ضمن «🌐 الشبكات والاتحادات ← بطاقة الشبكة» زر «📸 نسخ السياسات التاريخية». تعرض الشاشة «📸 حفظ نسخة من سياسة مجموعة» و«🕘 سجل النسخ التاريخية». تُعرض فقط المجموعات المعتمدة بإصدار عضوية الشبكة الحالي وتملك سجل سياسة حماية واحدًا صالحًا. الاختيارات مقسمة إلى صفحات من 8 مجموعات؛ المجموعات ذات السياسة القديمة أو المفقودة أو المكررة لا تحصل على زر حفظ.

## حفظ النسخة

1. يختار المالك المجموعة ويرى **معاينة قبل الحفظ** تعرض مُعرّف المجموعة وإصدار اعتمادها وإصدار السياسة ووضع الحماية وعدد قواعدها، مع تحذير واضح بشأن تخزين سياسة الحماية محليًا.
2. لا تتضمن المعاينة نصوص قواعد الحماية أو النطاقات أو بيانات المستثنين؛ وتُحفظ هذه القيم **داخل قاعدة البيانات الخاصة بالبوت** فحسب.
3. يولّد البوت تأكيدًا مستقلًا أحادي الاستخدام صالحًا لدقيقتين ومربوطًا بهوية المالك، والشبكة والمجموعة، والإصدارات وبصمة كل البيانات المعتمدة. يتوقف التنفيذ عند إلغاء الموافقة أو انتهائها أو تكرارها أو تغيّر أي إعداد أساسي قبل الضغط.
4. بعد التأكيد تُلتقط نسخة من سياسة الحماية نفسها داخل معاملة تخزين JSON/SQLite ذرية، مع بصمة SHA-256 لمحتوى النسخة وبيانات التقاطها. تظل **السياسة الحالية وروابط توريث الشبكات والمساعد والعقوبات كما هي**.
5. يحفظ البوت تدقيق القرار `OWNER_NETWORK_POLICY_SNAPSHOT_CAPTURED` دون أي محتوى حساس.

## ضوابط الأمان والتخزين

- لا يتجاوز السجل **100 نسخة إجمالًا** أو **5 نسخ لكل مجموعة داخل الشبكة**؛ عند بلوغ الحد يُرفض الالتقاط بدل حذف سجل قديم بصمت.
- لكل نسخة معرّف فريد، ومعرّف شبكة، وإصدار شبكة، ومعرّف مجموعة، وإصدار مجموعة، وإصدار السياسة، ووقت ومالك الالتقاط، ومحتوى السياسة، وبصمة تحقق من سلامة سجلها.
- يُدقق النموذج عند تحميل قاعدة البيانات وبعد كل معاملة، وتُرفض البصمات التالفة والنسخ المكررة وسجلات السياسات غير السليمة؛ لا تُصلح السجلات المتضررة ضمن هذا المسار.
- يمنع Telegram فتح أزرار أخذ النسخ أو رؤيتها من رسائل المجموعات؛ العمل فقط من خاص المالك وبعد تحقق الميزة `owner.dashboard`.
- سجل النسخ منفصل لكل شبكة مع صفحات؛ تُحسب مقارنة النسخة بالمحتوى الحالي لحظة فتحها. عند اختلاف سياسة المجموعة أو فقدان اعتمادها تُظهر الشاشة الحقول المتغيرة أو سبب عدم إمكانية المقارنة، من غير إظهار قيم القواعد أو المعرّفات الحساسة.
- لا يمنع إيقاف الطوارئ قراءة النسخ التاريخية؛ إذ لا تغيّر القراءة أو الالتقاط تشغيل المجموعة. أضيف لاحقًا استرجاع إعدادات **المجموعة نفسها فقط** بإيصال منفصل، مع حظر تفعيل ENFORCE؛ لا توجد أداة نسخ سياسة إلى مجموعة أخرى.
- البصمة المضمنة تكشف التغيير العرضي للبيانات ولكنها **ليست توقيعًا مشفرًا بأسرار مستقلة**؛ حماية النسخ الاحتياطية وملفات قاعدة البيانات تظل مسؤولية التشغيل، مع مراعاة حساسية محتوى قواعد الحماية.
