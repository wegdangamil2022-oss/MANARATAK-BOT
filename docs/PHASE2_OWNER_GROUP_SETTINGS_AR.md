# المرحلة الثانية — محرر إعدادات المجموعات المحلية

## مسارات لوحة المالك

تبدأ الشاشة من «👥 المجموعات والشبكات ← ⚙️ إعدادات القسم» أو «مجموعاتي ← بطاقة المجموعة ← ⚙️ إعدادات هذه المجموعة». تظهر قائمة المجموعات المعتمدة فقط، مع ثماني مجموعات لكل صفحة. يرفض الرابط عند تغيّر إصدار المجموعة أو انتقالها إلى صفحة أخرى أو إلغاء اعتمادها أو تكرار سجل اعتمادها بعد الاستعادة.

## أوضاع المساعد الذكي

يستطيع **المالك في الخاص فقط** اختيار `OFF` أو `OWNER_MENTION` أو `STAFF_MENTION` أو `ALL_MENTION` للمجموعة ذات نطاق `assistant` المحلي. لا يجوز رفع وضع المساعد إلى أحد أوضاع التفاعل دون هذا النطاق. يسمح بإيقاف المساعد `OFF` حتى إذا سُحب نطاق المساعد بعد ضبطه سابقًا. الوضع `ALL_MENTION` يعني السماح المحلي للسؤال عند المنشن، ولا يثبت أن نموذج الذكاء يعمل أو أن Telegram يرسل إليه الرسائل.

تُحفظ تغييرات وضع المساعد مع زيادة إصدار اعتماد المجموعة. **قد يجعل ذلك سياسة الحماية المحفوظة لإصدار سابق تحتاج إلى مراجعة**؛ تعرض المعاينة هذا التحذير ولا تُفعّل قواعد أو عقوبات تلقائيًا. ليست الشاشة وسيلة لتوسيع نطاقات التفويض، وإنما لتعديل خيار المساعد ضمن نطاق معتمد بالفعل.

## وضع قواعد الحماية

إذا كان للمجموعة نطاق `moderation` وسياسة حماية واحدة سليمة وراهنة، يمكن تبديل وضعها بين `OFF` و`MONITOR` فقط. تظل الكلمات والروابط والسماحات والعبارات كما هي، ويزداد إصدار سياسة الحماية مع تسجيل المالك والوقت. تُزال نوافذ الفلود المحلية القديمة التابعة للمجموعة عند تبديل الوضع حتى لا تُنسب أحداث قديمة إلى إعداد جديد.

لا يوجد خيار `ENFORCE`، ولا يُرسل أي أمر إلى Telegram، ولا يُحذف أو يُكتم أو يُحظر عضو. إذا لم توجد سياسة، أو كانت مكررة أو تالفة أو قديمة أو مستقبلية، لا يعرض المحرر زر تبديل وضعها؛ يجب معالجة الحالة أولًا من محرر الحماية.

## معاينة وحفظ وإلغاء

- كل إجراء حساس يبدأ بمعاينة توضح المجموعة والقيمة الجديدة وتأثيرها المحلي وحدود التشغيل.
- تصدر المعاينة مرجعًا عشوائيًا خادميًا، مرتبطًا بالمالك والمجموعة وإصدار اعتمادها وموضعها الحالي وتوقيع حالتها وإعدادات لوحة المالك. صلاحيته دقيقتان واستخدام واحد.
- عند التأكيد، تُعاد قراءة الصلاحيات والسجلات والمرجع داخل **معاملة تخزين ذرية واحدة**. أي تغير في المجموعات أو الإصدار أو السياسة المعنية أو إعدادات لوحة المالك يمنع الحفظ بلا تعديل جزئي.
- زر «✖ إلغاء المعاينة» يبطل المرجع في قاعدة البيانات؛ فلا يمكن إعادة استخدامه من رسالة قديمة، ويسجل الإلغاء في التدقيق.
- لا تقبل الشاشات السياق الجماعي أو مستخدمًا غير المالك. تُراجع مفاتيح `callback_data` وفق حد Telegram البالغ 64 بايت.

## سجل تغييرات المجموعة

توجد شاشة «🕘 سجل تغييرات إعدادات المجموعة» من بطاقة الإعدادات. تراجع سجل التدقيق المحلي وتقارنه مع رمز التأكيد المستهلك والمرتبط بالمالك والمجموعة. تظهر حتى ثماني عمليات للصفحة، وتُحجب الأحداث ذات الأدلة المكررة أو غير السليمة. السجل للقراءة فقط ولا يسترجع تلقائيًا القيم ولا يثبت تنفيذ أوامر Telegram. عند إلغاء اعتماد مجموعة يُرفض فتح سجلها من رابط قديم.

## التحقق وحدود الإنجاز

اختبارات `tests/owner-inline-group-settings.test.ts` تغطي JSON وSQLite: الصفحات، وصحة المفاتيح، وتغيير أوضاع AI، وتبديل MONITOR/OFF، وبقاء القواعد والسماحات، ورفض السياسة القديمة، والتأكيد المنتهي أو المتزامن، والإلغاء، وصلاحيات المالك، والاعتماد الملغى، وسجل الإعدادات وتعارض الأدلة. تعمل ضمن `npm run check` مع بقية اختبارات المشروع.

**لا تعني هذه الدفعة إغلاق المرحلة الثانية**، ولا تحقق فحص الحقوق الحية، أو تشغيل الحماية التلقائية، أو ضبط اللغة والتوقيت والمواضيع والشبكات الاتحادية، أو استرجاع جميع إصدارات الإعدادات السابقة. تلك متطلبات مستقلة ما زالت مفتوحة.
