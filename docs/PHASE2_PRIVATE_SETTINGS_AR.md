# مفاتيح خدمات الخاص — التنفيذ المحلي

يفتح «🤖 المساعد الذكي ← 💬 ذكاء الخاص» شاشة لمفاتيح مستقلة: أسئلة الخاص، تصفح التعليم، الدعم، التحقق من الاشتراك، لوحة المالك، ورفع الملفات. تعرض الشاشة حالة السياسة المحفوظة، ولا تدّعي اكتمال خدمة الدعم أو تشغيل مزود خارجي. تغيير مفتاح لا يغير المفاتيح الأخرى.

كل تغيير يمر بمعاينة ثم تأكيد مرتبط بالمالك وإصدار الحالة وصالح لدقيقتين. تستهلك المعاملة التأكيد مرة واحدة، وتسجل التغيير وتتحقق من أن القيم الحالية لم تتغير؛ الأزرار القديمة أو المكررة أو ذات أعلام غير سليمة مرفوضة. مراجعة حالة القيم لا ترسل طلبات شبكة.

عند إيقاف لوحة المالك تُحجب لوحاتها وأزرارها، بينما تبقى خدمات الطالب المستقلة خاضعة لمفاتيحها. يستعيدها المالك من خاص البوت عبر `/ownerrecover` ثم المعاينة والتأكيد. شاشات المالك المرتبطة بهذه الواجهات، إذا انتظرت في طابور الردود، يعاد فحص إذن اللوحة وإصدار الإعدادات قبل إرسالها؛ عند سحب الإذن لا تُرسل الشاشة القديمة. شاشة الاستعادة نفسها تبقى متاحة للمالك.

## الدليل والحدود

اختبارات `owner-inline-private-settings.test.ts` تشمل JSON وSQLite، تبديل المفاتيح مع فحص بوابات الملاحة والرفع والاشتراك، الموافقة على أسئلة الخاص، إيقاف اللوحة واستعادتها، انتهاء التأكيد وتكراره وتغير الحالة، ومنع إرسال شاشة مالك بعد إغلاق اللوحة. اختبارات حماية الطابور السابقة تظل مطبقة.

هذا تنفيذ محلي لواجهة المفاتيح وبواباتها القائمة. خدمة الدعم الكاملة وربط مزود ذكاء اصطناعي أو اختبار Telegram الحي ليست مثبتة هنا. يظل مطلب ASKCFG-003 مفتوحًا إلى استكمال المسارات التي لم تُنفذ ومراجعة سياقات التشغيل وفق الخطة.
