# محرك قواعد الحماية المحلي وسياسات المجموعات

شريحة تنفيذية مرتبطة بـLEX-001/002/003/006/007 وSPAM-001/006/011 وTYPELOCK-001/009، لا إغلاق كامل لهذه المطالب.

## المبرمج

- قواعد كلمة كاملة وعبارة متجاورة وترتيب كلمات، وروابط بحسب المضيف، وأنواع رسائل محددة. تعمل على النص أو شرح الوسيط؛ ويمكن تمرير روابط كيانات Telegram صراحةً إلى المحرك.
- تطبيع Unicode والتشكيل والتطويل وبعض صور الألف والياء، دون اشتقاق لغوي أو مساواة ة وه. لا يسمح المحرك بتعبير regex يأتي من المستخدم.
- استثناء عبارة مسموحة في موضعها فقط، دون إعفاء بقية الكلمات أو قفل الوسائط. تبقى حدود بين طرفي العبارة المستثناة حتى لا تتولد مخالفة كاذبة بضم كلمات كانت متباعدة.
- أسماء المضيفين المسموحة تطابق بالضبط؛ school.edu.evil.test والروابط ذات بيانات دخول لا تصبح موثوقة بسبب ظهور school.edu في النص. لا يجلب المحرك روابط ولا يحل اختصارات أو Redirect أو DNS.
- نتيجة واحدة بأشد إجراء مقترح، ومعرفات القواعد المطابقة فقط، دون إعادة نص الطالب أو تخزينه. لا يُقترح حظر دائم.
- قواعد معطلة ووضع OFF وقائمة إعفاء صريحة، وتحقق من النطاق والمدخلات والأحجام وأنواع enum دون تحويل قيم غير نصية إلى نص.

لا تعني نتيجة MATCH إذنًا بعقوبة. authorizedToSend=false دائمًا؛ القرار يحتاج طبقة تفويض وتنفيذ مستقلة. INVALID_MESSAGE وINVALID_POLICY ليستا CLEAR.

## حفظ السياسات

GroupProtectionPolicyService يحفظ سياسة مراقبة OFF/MONITOR لكل مجموعة مخولة، مع نسخة السياسة ونسخة اعتماد المجموعة والفاعل والوقت وسجل تدقيق دون نصوص عينات الاختبار. يُرفض حفظ ENFORCE ما دام المنفذ غير موصول.

- يفحص chat.manage ونطاق moderation داخل معاملة الحفظ.
- يمنع الكتابة فوق نسخة أحدث عند تزامن محررين.
- سحب اعتماد المجموعة أو إعادة اعتمادها لا ينشطان سياستها القديمة تلقائيًا.
- الساعة المتراجعة لا تعيد كتابة سياسة من المستقبل أو تعرضها كسياسة حالية.
- الدليل اختباري على JSON وSQLite وإعادة الفتح؛ حقل إضافي اختياري في schemaVersion 8، ولا تهيئة آلية لسجلات السياسات في الملفات القديمة.
- يُرفض حفظ/استعادة سجل مشوه أو مكرر وتُحفظ الحالة السابقة عند فشل معاملة.

الحدود الحالية للاختبار: 100 قاعدة، و100 عنصر لكل قائمة سماح/إعفاء، ونص رسالة حتى4096 وحدة UTF-16، و500 سجل مجموعة. ليست أرقام أداء أو ضمان تغطية لغوية.

## واجهة الكلمات والعبارات ومراقبة النص

تتوفر واجهة خاصة للمالك والمشرف المفوض من زر «🚫 الكلمات والعبارات»، مع إضافة وتعديل وتفعيل القواعد وتحديد الإجراء المقترح وحذف بتأكيد. الاختبار يعرض المطابقات دون حفظ العينة. مراقبة الرسائل النصية الواردة تسجل عدد المطابقات والنسخة والإجراء المقترح فقط؛ لا ترسل عقوبات. تفاصيل الربط وحدوده في [واجهة الحماية](PROTECTION_EDITOR_AR.md).

## التشغيل المحلي

```bash
npm run demo:protection
npm run check
node --test dist/tests/protection-rules.test.js dist/tests/group-protection-policy.test.js
```

تجربة العرض تحفظ MONITOR في SQLite مؤقتة، وتختبر رسالة وهمية وتقترح إجراء واحدًا، وتثبت منع تفعيل منفذ غير موصول. تحذف قاعدة التجربة بعد الانتهاء، ولا تستخدم Telegram أو مزودًا خارجيًا.

## المتبقي

واجهات السماح والاستثناءات والروابط وأنواع الرسائل، استقبال الوسائط والتعديلات، قوائم الشبكات المركزية، الفلود وAntiRaid، المنشن والتوجيه، تحليل الصور/OCR الاختياري، الاستئناف والقياس، وربط الأثر بالخدمات المشتركة؛ ليست مبرمجة بهذه الشريحة. لا تدعي الشاشة أو الخدمة أن فلاتر Telegram حية أو أن جميع متطلبات الحماية استوفيت.
