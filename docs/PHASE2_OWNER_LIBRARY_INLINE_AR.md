# المرحلة الثانية — مسار إدارة المكتبة للمالك

المدخل المعتمد «📚 إدارة المكتبة» يعرض الموارد المنشورة المتاحة، ثمانية موارد لكل صفحة، ثم تفاصيل المورد ومعاينة الأرشفة والتأكيد والإلغاء. تعرض التفاصيل الطويلة في صفحات من 200 رمز Unicode دون اقتطاع بيانات المورد، وبنفس بصمة الاختيار. تعدل الانتقالات الرسالة الحالية وتحفظ صفحة الرجوع. بعد أرشفة آخر مورد في آخر صفحة يرجع الزر إلى آخر صفحة صالحة. تبقى أسماء وترتيب المداخل المعتمدة كما هي.

كل ضغطة تتطلب المالك في الخاص وإتاحة لوحة المالك. لا تعرض الموارد التابعة لنطاق غير معتمد، وتحجب المعرفات المكررة. تتضمن بصمة الاختيار بيانات المورد ونسخة سياسة المجموعة؛ تغيير المورد أو سحب اعتماد المجموعة يبطل الاختيار السابق.

تنتج المعاينة مرجع تأكيد عشوائيًا محفوظًا مرتبطًا بالمالك والمورد والنطاق ونسخة السياسة، صالحًا لدقيقتين ولمرة واحدة. يعاد التحقق من جميع الشروط وصلاحية النشر قبل استهلاك المرجع وأرشفة المورد وتسجيل التدقيق في معاملة واحدة. المرجع المنسوخ أو المكرر أو المنتهي أو المتأثر برجوع الساعة مرفوض. تتحقق الخدمة من أن وقت الانتهاء عدد صحيح آمن وأن أعلام الاستخدام والسحب والتأكيد أحادي الاستخدام قيم منطقية صحيحة؛ السجل المستعاد ذو الأنواع المحرفة لا يمنح تأكيدًا. لا ترسل هذه العملية رسائل أو حملات؛ تغير حالة المورد المحلي فقط.

التنفيذ في `src/telegram-inline-library.ts` و`src/education.ts` والربط في `src/telegram-transport.ts`. اختبارات `tests/owner-inline-library.test.ts` تشمل JSON وSQLite، التزامن وإعادة الاستخدام والصلاحيات وتغير البيانات والصفحات وسحب الاعتماد وتكرار السجلات وحدود صيغة callback.

هذا يغلق مسار عرض الموارد وأرشفتها ضمن واجهة المرحلة الثانية محليًا. لا يغلق قسم التعليم كاملًا أو المرحلة الثانية: محرر التصنيفات وبقية المداخل والإعدادات ومعالج المجموعة ومحرر القوالب والأزرار ما زالت تحتاج تنفيذًا وتحققًا حسب MASTER. اختبار Telegram الحي مؤجل حسب قرار المالك.

- بناء TypeScript ناجح؛ 15 اختبار مكتبة ناجحًا، و78 اختبار توافق مركزًا ناجحًا بعد إضافة اختبار صفحات التفاصيل الطويلة ورفض أنواع سجلات التأكيد المحرفة في FAQ والمكتبة.
- تدقيق المرحلة الأولى ناجح لجميع الأزرار الـ253 على JSON وSQLite دون طلبات شبكة أو تغيير حالة الأعمال؛ تدقيق سجل MASTER ناجح للمتطلبات الـ703.
