# تنفيذ قواعد الحماية — نطاق محلي

تدعم خدمة السياسة وضع ENFORCE فقط عند حقن منفذ تنفيذ يدعم جميع إجراءات القواعد المفعلة والفلود. المنفذ الحالي يعيد استخدام ModerationService للمراجعة والتحذير والكتم لمدة دقيقة واحدة. لا ينفذ DELETE؛ وجود قاعدة حذف مفعلة يحجب التفعيل وتغيير سياسة تنفيذ قائمة إلى إعداد غير مدعوم. الوضع الافتراضي بلا منفذ يظل مراقبة فقط. لم يتغير خادم التشغيل الحي ولم تُرسل طلبات Telegram.

تُعرض مراجعة مستقلة قبل التفعيل. التأكيد خاص بالفاعل والمجموعة وبصمة السياسة ومرجع عشوائي لمرة واحدة لمدة دقيقتين. الرجوع والتنقل والنص الخاص واستبدال المعاينة تلغي التأكيد؛ تغيّر النسخة أو التفويض يمنع حفظ التفعيل. تُربط المعاينة المؤجلة بجلسة التأكيد حتى لا تُرسل بعد إلغائها.

يسجل التقييم مطالبة دائمة قبل أي قراءة خارجية أو تنفيذ، دون تخزين النص أو الوسائط. إعادة وصول التحديث لا تعيد المحاولة. يُراجع التفويض الحالي لمحرر السياسة وموافقة المجموعة ونسختها والاستثناءات وحماية المالك والمشرفين. يُعاد فحص السياسة والمهلة البالغة خمس ثوان داخل معاملة التحذير أو السبب بعد القراءات الخارجية. للكتم شاهد مستقل يستمر إلى حجز الإرسال وحده الأخير؛ إيقاف السياسة بعد حفظ السبب يلغي الإرسال. يبقى السبب المحفوظ المحدد بدقيقة في السجل للمراجعة/الانتهاء؛ لا يُلغى بأثر رجعي بما قد يخفي محاولة قائمة.

الكتم يستخدم سجل الأسباب والعمليات وفيوز المعدل وحجر النتيجة المجهولة الموجودة. لا يوجد سجل عقوبات موازٍ أو إعادة تلقائية. التحذير يبقى تحذيرًا محليًا؛ لا يتحول تلقائيًا إلى حظر. تُحترم مدد الأسباب الأخرى ولا يفتح هذا المسار أي قيد مستقل. انتهاء الأسباب عبر tick يظل معطلًا افتراضيًا كما هو موثق في وثيقة المرحلة.

تمرر خدمة تحديثات Telegram المنفذ المحقون إلى فحص النصوص والوسائط والتعديلات وإعادة التوجيه ومحرر السياسة. التعديلات لا تزيد عداد الفلود. يحتفظ تقييم القواعد بالحقل authorizedToSend=false؛ نتيجة المطابقة ليست صلاحية تنفيذ بحد ذاتها.

الاختبارات على JSON وSQLite تغطي غياب المنفذ والإجراء غير المدعوم والاستثناءات وحماية الهدف والتكرار والمهلة والتفويض وتغير السياسة بعد القراءات، وإلغاء كتم بعد INTENT، وتمرير النص والوسائط والتعديلات عبر التطبيق، والتفعيل الخاص والرجوع والاستبدال والانتهاء وبطلان المعاينة المؤجلة. الحذف التلقائي والتدرج العقابي وAntiRaid والاستثناءات المؤقتة وربط التشغيل الآمن ما زالت متطلبات مفتوحة؛ لا تغلق هذه الشريحة المرحلة الثالثة.
