# توضيح فقرة القانون والاعتراض الخاص

تنفيذ محلي لمسار RULELAW-005، مع تأجيل تجربة Telegram الحقيقية بطلب المستخدم. لا يغلق هذا المستند المرحلة الثالثة أو إخفاقات الفحص الشامل.

يفتح العضو `/appeals` في الخاص ويختار حالته اليدوية. تعرض الحالة المرتبطة بقانون زر «توضيح فقرة القانون»، سواء كانت تحذيرًا أو كتمًا. يفتح الزر النص المعتمد في الإصدار الأصلي ورقم الفقرة ومرجع الرسالة ونوع الإجراء وموعد الانتهاء المسجل إن كان صالحًا، دون نص رسالة العضو أو أسماء أعضاء آخرين. يُهرب النص قبل عرضه بصيغة HTML، ولا يستبدل بنص قانون أحدث أو ترجمة غير معتمدة.

التوضيح للقراءة فقط: لا ينشئ اعتراضًا أو تذكرة أو تحذيرًا ولا يستدعي Telegram ولا يغير العقوبة. يوفر الرجوع إلى طلب المراجعة وإلى الحالات. يتطلب تسجيل طلب المراجعة التأكيد الخاص الموجود، ثم تعرض نافذة المشرف المخول الطلب. قبول الاعتراض لا يرفع قيدًا تلقائيًا؛ إلغاء تحذير محدد يبقى عملية مستقلة بتأكيدها وضوابطها القائمة.

تظل قائمة الحالات مرتبطة بصاحب الحساب وبصلاحية قسم الدعم والمجموعة. الزر لا يصلح لحساب آخر أو في المجموعة، ويُبطل عند تغير المصدر أو القانون أو التفويض. لا يعرض توضيحًا موثوقًا عند تعدد المصادر المتطابقة أو غياب القانون التاريخي. ينقل سجل الاعتراض الخاص وشاشة المشرف تفسير القانون القديم للكتم أيضًا، وتعرض حالات الإشراف المخولة الفقرة التاريخية لجميع أنواع الحالات المرتبطة بقانون.

نافذة الاعتراض هنا واجهة خاصة، كما ينص المطلب الرسمي. لم يُخترع لها موعد نهائي جديد أو تُغير سياسة المهل؛ تبقى حدود الطلبات والتأكيدات وسلوك الحالات النشطة كما كانت. التنبيه الأول ليس قيدًا أو تحذيرًا محتسبًا ولا يتحول ضمنيًا إلى حالة عقوبة يطلب العضو رفعها.
