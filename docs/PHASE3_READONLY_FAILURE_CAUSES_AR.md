# أسباب رفض القراءة الآمنة

يحفظ مسار القراءة فقط لملف SQLite رسالة الرفض العامة القائمة، ويضيف سببًا ثابتًا داخل `Error.cause`. يشمل السبب مسارًا غير صالح، أو ملفًا غير متاح، أو نوع ملف غير مقبول، أو صلاحيات ملف غير خاصة، أو مسارًا غير مطابق، أو محتوى غير صالح، أو تعذر الفتح. لا يتضمن السبب اسم الملف أو مساره أو محتواه أو أسرار التشغيل. يحفظ فحص قبول التجربة هذه السلسلة عند رفض المصدر أو النسخة الاحتياطية.

تبقى شروط القبول كما هي، ويستمر رفض الملف عند الإخفاق. يحتفظ تقرير المتطلبات بتصنيف الإخفاق «صلاحيات ملف المضيف» فقط عند وجود سبب صريح `SQLITE_READONLY_PRIVATE_MODE_REQUIRED` أو رسالة رفض صلاحيات صريحة. لا يتغير الاختبار الفاشل إلى ناجح بسبب تصنيف سببه، ولا تُنسب الرسائل العامة المتبقية تلقائيًا إلى Windows.

تغطي الاختبارات بقاء الرسالة العامة، وسبب رفض الملف الحقيقي بعد طلب صلاحية 0600، وسلسلة السبب عبر فحص التجربة، وعدم تضمين المسار في نص السبب، ورفض المسارات النسبية. يتطلب إثبات قبول التشغيل بيئة تستطيع تطبيق شروط الملفات الحالية واستكمال بقية فحوص المرحلة. اختبار Telegram الحقيقي مؤجل بطلب المستخدم.
