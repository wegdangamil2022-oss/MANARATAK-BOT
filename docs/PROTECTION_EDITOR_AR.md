# واجهة الكلمات والعبارات ومراقبة النص محليًا

هذه شريحة من LEX-001 وLEX-007 وSPAM-011؛ لا تغلق الحماية أو المراحل الأربع. المرجع الكامل MASTER، وليست قائمة الأزرار المختصرة معيارًا للاكتمال.

## المسار المبرمج

يفتح المالك «🚫 الكلمات والعبارات» في قسم الحماية، ويصل المشرف المفوض إليه من بطاقة مجموعته الإشرافية. تعرض القوائم المجموعات المعتمدة لنطاق moderation التي يملك الفاعل فيها chat.manage، بثمانية عناصر لكل صفحة، ثم إعدادات المجموعة وقواعدها.

يمكن إضافة كلمة أو عبارة وتعديل نصها وتفعيلها وتعطيلها وتحديد إجراء مقترح وحذفها بعد تأكيد. تبدأ القاعدة معطلة بإجراء مراجعة. تتوفر أوضاع OFF وMONITOR؛ لا يمكن تفعيل ENFORCE. تبقى الإجراءات المقترحة وصفًا لنتيجة الفحص دون إرسال حذف أو كتم.

اختبار القواعد يفحص عينة داخل الذاكرة مع القواعد المعطلة أيضًا، ويعرض نسخة السياسة والقواعد المطابقة والإجراءات المقترحة. لا يعيد العينة في الرد ولا يخزنها. قواعد المشرف المدخلة للإعداد تخزن بوصفها إعدادات صريحة.

## الصلاحية والتزامن

- تربط المحددات المجموعة والصفحة بنسخة اعتماد المجموعة وإعداداتها؛ يرفض المحدد القديم بعد تغيير السياسة.
- ينتهي انتظار إدخال النص بعد خمس دقائق، ويستهلك مرة واحدة، ويلغى بالتنقل. لا يخزن نص الإدخال في جلسة الانتظار. تمديد صلاحية جلسة مستعادة أو تكرارها لا يمنح إذنًا.
- يعاد فحص التفويض والنسخ داخل معاملة الحفظ. سحب الصلاحية أثناء انتظار النص يمنع الحفظ.
- ترتبط الشاشات الخاصة في طابور الإرسال بالفاعل وشاهد لحالة التفويض والإعدادات والجلسة، لمدة لا تتجاوز دقيقتين. يعاد حساب الشاهد قبل الإرسال؛ تغير الصلاحية أو السياسة أو انتهاء المدة يمنع إرسال الشاشة ويزيل محتواها من السجل النهائي.
- الشاهد المحلي مقارنة حالة، وليس توقيعًا يحمي من استبدال قاعدة البيانات بالكامل. يلزم الحفاظ على صلاحيات ملفات الحالة كالمعتاد.

## مراقبة الرسائل

يمر النص الوارد في مجموعة معتمدة عبر سياسة MONITOR الحالية. تعالج روابط كيانات URL وtext_link دون جلبها، وتتحقق حدود UTF-16 كي لا يقص موضع كيان زوج Unicode. البيانات المشوهة تسجل تعذر الفحص، ولا تعد رسالة سليمة.

يسجل التطابق مرة واحدة لكل تحديث: نسخة السياسة وعدد القواعد والإجراء المقترح فقط. لا يسجل النص أو الروابط أو هوية مرسل العينة. يعفى المالك والمشرف المفوض والأعضاء المستثنون صراحةً. لا تنفذ عقوبة ولا ينشر رد في المجموعة.

المسار الحالي للرسائل النصية العادية فقط. استقبال الوسائط وشرحها والتعديلات وأحداث الأعضاء والفلود وAntiRaid وواجهات السماح والقواعد المركزية والتنفيذ الآلي متبقٍ. تجربة Telegram الحية مؤجلة بطلب المالك.

## التحقق

`npm run check` نجح مع 2541 اختبارًا. ملف `tests/telegram-protection-editor.test.ts` يضم 41 اختبارًا للمسار الجديد على JSON وSQLite: التعديل والتأكيد والصلاحيات وانتهاء الجلسات والتزامن وحجب الردود القديمة ومراقبة النص وخصوصية العينات. نجح جرد 253 زرًا لكل محرك، مع 12 مدخل عرض محلي و241 مدخلًا وصفيًا؛ هذه الأعداد لا تعني تنفيذ كل متطلبات MASTER.
