# واجهة قواعد الحماية ومراقبة الرسائل محليًا

هذه شريحة من LEX-001 وLEX-007 وSPAM-001 وSPAM-011 وTYPELOCK-004؛ لا تغلق الحماية أو المراحل الأربع. المرجع الكامل MASTER، وليست قائمة الأزرار المختصرة معيارًا للاكتمال.

## المسار المبرمج

يفتح المالك «🚫 الكلمات والعبارات» أو «🔗 الروابط والتوجيه» أو «🔒 أقفال أنواع الرسائل» أو «✅ الاستثناءات والسماح» في قسم الحماية، ويصل المشرف المفوض إليه من بطاقة مجموعته الإشرافية. تعرض القوائم المجموعات المعتمدة لنطاق moderation التي يملك الفاعل فيها chat.manage، بثمانية عناصر لكل صفحة، ثم إعدادات المجموعة وقواعدها.

يمكن إضافة كلمة أو عبارة وتعديل نصها وتفعيلها وتعطيلها وتحديد إجراء مقترح وحذفها بعد تأكيد. يمكن كذلك إضافة قاعدة لجميع الروابط أو لنطاق محدد ونطاقاته الفرعية، واختيار واحد من 12 نوع رسالة على صفحتين. تعرض تفاصيل القاعدة أسماء مفهومة بدل معرفاتها الداخلية، ولا تكرر إضافة هدف نوع أو جميع الروابط الموجود. تبدأ القاعدة معطلة بإجراء مراجعة. تتوفر أوضاع OFF وMONITOR؛ لا يمكن تفعيل ENFORCE. تبقى الإجراءات المقترحة وصفًا لنتيجة الفحص دون إرسال حذف أو كتم.

اختبار القواعد يفحص عينة داخل الذاكرة مع القواعد المعطلة أيضًا، ويعرض نسخة السياسة والقواعد المطابقة والإجراءات المقترحة. لا يعيد العينة في الرد ولا يخزنها. قواعد المشرف المدخلة للإعداد تخزن بوصفها إعدادات صريحة.

## قوائم السماح

تسمح الشاشة بإضافة نطاق مسموح أو عبارة تعليمية مسموحة، وعرض القائمتين بصفحات من ثمانية عناصر وإزالة العنصر بتأكيد مرتبط بنسخة السياسة. النطاق يطابق المضيف بالضبط؛ لا يمنح سماحًا للنطاقات الفرعية تلقائيًا. العبارة تعفى في موضعها فقط ولا تعطل قاعدة نوع الرسالة أو كلمة مخالفة خارجها. يرفض المدخل المشوه أو المكرر أو المتجاوز للحد، وتعرض النصوص الطويلة باختصار آمن ضمن حدود Telegram. الإعفاءات الشخصية المؤقتة وحوكمة الشبكات والقوائم المركزية ما زالت متبقية.

## الصلاحية والتزامن

- تربط المحددات المجموعة والصفحة بنسخة اعتماد المجموعة وإعداداتها؛ يرفض المحدد القديم بعد تغيير السياسة.
- ينتهي انتظار إدخال النص بعد خمس دقائق، ويستهلك مرة واحدة، ويلغى بالتنقل. لا يخزن نص الإدخال في جلسة الانتظار. تمديد صلاحية جلسة مستعادة أو تكرارها لا يمنح إذنًا.
- يعاد فحص التفويض والنسخ داخل معاملة الحفظ. سحب الصلاحية أثناء انتظار النص يمنع الحفظ.
- ترتبط الشاشات الخاصة في طابور الإرسال بالفاعل وشاهد لحالة التفويض والإعدادات والجلسة، لمدة لا تتجاوز دقيقتين. يعاد حساب الشاهد قبل الإرسال؛ تغير الصلاحية أو السياسة أو انتهاء المدة يمنع إرسال الشاشة ويزيل محتواها من السجل النهائي.
- الشاهد المحلي مقارنة حالة، وليس توقيعًا يحمي من استبدال قاعدة البيانات بالكامل. يلزم الحفاظ على صلاحيات ملفات الحالة كالمعتاد.

## مراقبة الرسائل

يمر النص أو الوسيط المدعوم الوارد في مجموعة معتمدة عبر سياسة MONITOR الحالية. تعالج روابط كيانات URL وtext_link دون جلبها، وتتحقق حدود UTF-16 كي لا يقص موضع كيان زوج Unicode. البيانات المشوهة تسجل تعذر الفحص، ولا تعد رسالة سليمة.

يسجل التطابق مرة واحدة لكل تحديث: نسخة السياسة وعدد القواعد والإجراء المقترح فقط. لا يسجل النص أو الروابط أو هوية مرسل العينة أو معرفات الملفات أو أرقام جهات الاتصال أو المواقع أو محتوى الاستطلاع. يعفى المالك والمشرف المفوض والأعضاء المستثنون صراحةً. لا تنفذ عقوبة ولا ينشر رد في المجموعة.

يتعرف المسار على الصور والفيديو وGIF والملصقات والمستندات والصوتيات والرسائل الصوتية والدوائر المرئية وجهات الاتصال والمواقع والاستطلاعات. يقيّم الشرح وروابط كياناته دون تنزيل الوسيط. يصنف GIF مرة واحدة عند إرفاق Telegram حقل document للتوافق القديم. تبقى مستندات المجموعة ممنوعة من مسار الاستيراد الإداري حتى عند مراقبتها. يرفض الرسائل ذات الأنواع المتعارضة أو بيانات النوع المشوهة.

تراقب تحديثات edited_message النصية وشروح الوسائط في المجموعات عبر السياسة نفسها، دون تنفيذ أوامر أو إرسال رد أو استيراد ملف من التعديل. يرفض غلاف التعديل الخاص أو المشوه أو المختلط برسالة/زر آخر.

التوجيه وأحداث الأعضاء والفلود وAntiRaid وحوكمة السماح والقواعد المركزية والتنفيذ الآلي متبقٍ. تجربة Telegram الحية مؤجلة بطلب المالك.

## التحقق

`npm run check` نجح مع 2573 اختبارًا. ملف `tests/telegram-protection-editor.test.ts` يضم 73 اختبارًا للمسار الجديد على JSON وSQLite: التعديل والتأكيد والصلاحيات وانتهاء الجلسات والتزامن وحجب الردود القديمة ومراقبة النص وخصوصية العينات. نجح جرد 253 زرًا لكل محرك، مع 15 مدخل عرض محلي و238 مدخلًا وصفيًا؛ هذه الأعداد لا تعني تنفيذ كل متطلبات MASTER.
