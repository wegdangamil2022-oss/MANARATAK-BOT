# NETWORK-006 — لوحة الأحداث الإدارية الموحدة (الشريحة الأولى)

## النطاق المنفذ
في خاص المالك: «🌐 الشبكات والاتحادات ← الشبكة ← 🔔 الأحداث الإدارية للشبكة».
لوحة للقراءة فقط، تجمع المواقف المحلية المسجلة مسبقًا من ثلاثة مصادر: بلاغات المراقبة NETWORK-003، ومقترحات المراجعة البشرية للعقوبات، وحالة قرار طوارئ الشبكة NETWORK-004. تُرتب الأحدث أولًا (الوقت UTC) وتُصفح ثمانية أحداث لكل صفحة، مع حد 200 حدث معروض.

لا تفتح هذه اللوحة قناة Telegram جديدة، ولا ترسل إشعارًا تلقائيًا، ولا تطبق حظرًا أو كتمًا أو تمنح مسؤولًا أذونات. لا تُعرض هوية العضو المبلّغ عنه أو محتوى البلاغ أو أسباب العقوبة. يظهر فقط نوع الحدث وحالته ومعرف المجموعة المعتمدة التي يرتبط بها. لا تُدرج سجلات مجموعات خارج الشبكة أو موافقات عضوية قديمة أو ملغاة. يتطلب العرض هوية مالك البوت ولوحة المالك المفعلة، وإذن إدارة المجموعة الحالي للأحداث المقيدة بالمجموعات.

**القيود المتعمدة:** ليست لوحة إرسال تنبيهات فورية بعد؛ لا يوجد تخزين اشتراكات مستلمين أو مرشحات فردية للمسؤولين، ولا إسقاط كامل لأحداث إدارة العضويات أو كل أنواع تدقيق الشبكات. يظهر آخر وضع محفوظ للطوارئ، وليس كل انتقالاتها التاريخية. لا يجوز اعتبارها إغلاق NETWORK-006 أو المرحلة الثالثة.

## الأمان والاختبارات
يرفض المحرك أحداث الشبكات ذات الهوية المكررة أو السجلات المشوهة، ويُعيد التحقق من الاعتماد والإصدار والصلاحية عند كل صفحة. شاشة القراءة لا تنشئ موافقات مؤقتة ولا تغير حالة التخزين.

اختبارات `tests/owner-network-events-inline.test.ts` تغطي JSON وSQLite، والعزل بين شبكتين، وعدم كشف هوية الأعضاء، وعدم حدوث تعديل، وسقوط اعتماد المجموعة، ورفض المستخدم غير المالك.

لا يثبت نجاح الاختبارات المحلية صلاحية التشغيل الحقيقي على Telegram. يبقى PR #184 مسودة وغير مدمج ولا تتغير المرحلة الرابعة PR #186.
