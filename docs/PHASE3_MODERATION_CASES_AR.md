# العقوبات والتحذيرات — واجهة الحالات المحلية

أصبح المدخلان الرسميان 02:02 و02:03 يفتحان مجموعات الفاعل المخولة، ثم قائمة الحالات بتقسيم ثماني حالات للصفحة، وتفاصيل الحالة وعدد التحذيرات النشطة والمدة إن وجدت. توجد روابط مماثلة للمشرف المفوض. الرجوع يحفظ صفحة الحالات، وتعرض القائمة طريقة بدء إجراء جديد بالرد على رسالة بشرية داخل المجموعة؛ لا اختيار عضو عشوائي من اسم أو نص.

الحالة المحلية النشطة لا تعني ثبوت قيد Telegram الحالي. يُعرض هذا الفرق داخل الواجهة. أسباب الاشتراك مستقلة ولا يظهر لها زر إلغاء يدوي. إلغاء سبب يدوي أو تحذير مسجل يفتح ModerationCommandReview الموجود، مع الفحص الخارجي للصلاحيات وحماية العضو والتأكيد الخاص لمرة واحدة؛ فتح التفاصيل لا ينفذ تغييرًا. عند تعذر المصدر أو حماية الهدف يُرفض إعداد المعاينة. سجل الاعتراضات والطرد والاستعادة الفعلية لقيد قائم تظل غير مكتملة ويظهر ذلك بوضوح.

تربط بصمة محدد الحالة الفاعل بالمجموعة والحالات ونسخة الموافقة والتفويض وسجل العمليات؛ لا يمكن نقل محدد مالك إلى مشرف آخر أو استخدام صفحة قديمة بعد تغيير حالات المصدر. تراجع كل نقرة التفويض، وتربط أدلة التسليم الإدارية بالمصادر الحالية. المدخل الرسمي للمالك لا يفتح للمشرف؛ يستخدم المشرف روابطه المحددة.

الاختبارات على JSON وSQLite تمر عبر تطبيق التحديثات الفعلي: عرض المالك والمشرف، رفض الطالب ونسخ محددات الفاعل والمجموعة، معاينة إلغاء تحذير وتأكيده مرة واحدة، بطلان المحدد القديم، صفحتا الحالات والمجموعات، حفظ صفحة الرجوع، حماية سبب الاشتراك، وسحب التفويض. لا شبكة أو قاعدة أصلية في الاختبارات.
