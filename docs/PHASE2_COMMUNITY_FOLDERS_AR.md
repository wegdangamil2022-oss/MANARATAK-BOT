# مجلدات المجتمع — إدارة الرابط والتحقق المستقل

حالة 2026-11-01: ربط الزر 03 في قسم «الانضمام والاشتراكات» بمسار محلي فعلي. هذا دليل للشريحة، وليس إغلاقًا للمرحلة الثانية أو قبولًا حيًا على Telegram.

يفتح المالك قائمة النطاقات المعتمدة للتصفح والتحقق في صفحات من ثمانية، ثم بطاقة المجموعة. يمكن إدخال رابط المجلد في رسالة خاصة، وفتح معاينته، ثم حفظه وإتاحته بتأكيد مستقل. يتطلب التعطيل وإعادة الإتاحة أيضًا معاينة وتأكيدًا. الرجوع أو الانتقال لوظيفة أخرى يلغي التأكيدات والمدخلات السابقة خادميًا ويحجب معايناتها المؤجلة. الإدخال والتأكيد صالحان لدقيقتين، والمراجع الفردية عشوائية مرتبطة بالضاغط والخاص والمصدر، وبحد 128 لكل مستخدم ومسار.

الرابط المقبول بنيويًا هو https://t.me/addlist/ متبوعًا بمعرّف من حروف وأرقام وشرطة أو شرطة سفلية، دون نطاق بديل أو بيانات دخول أو منفذ أو استعلام أو جزء مرجعي أو ترميز للمسار. لا يثبت فحص البنية أن الرابط موجود أو صحيح فعليًا؛ ينشئه المالك ويراجعه في Telegram. لا ينشئ البوت مجلدًا أو ينضم نيابة عن الطالب، ولا يقرأ محتوياته أو يدّعي أن إضافته أكملت العضوية.

تظهر «مجلدات المجتمع» في الرئيسية للطلاب عند وجود رابط متاح لمجموعة معتمدة وقاعدة اشتراك نشطة. القائمة العامة تعرض فقط هذه المداخل، ثم زر URL للمجلد وزر مستقل «تحقق من الاشتراك». التحقق يستعمل SubscriptionGate القائمة وقاعدة ALL/ANY/AT_LEAST المحفوظة، بما فيها الحد الأدنى العددي. لا تغيّر إضافة المجلد أو ضغطة التحقق القاعدة، ولا تمنح عضوية بالمجموعة أو تصريح وصول إلى محتواها. تعذر الفحص ليس مخالفة. يعرض استثناء المالك بوصفه استثناءً، لا نتيجة عضوية مؤكدة.

يرتبط كل رد عام مؤجل بشاهد COMMUNITY_SCOPED مستقل عن المكتبة الخاصة، يشمل إتاحة التعليم واعتمادات الجهات وقواعد الاشتراك وروابط المجلدات. يحجب الطابور الرابط أو نتيجة قديمة بعد تغير هذه المصادر أو انتهاء المهلة، ويمحو الشاهد والمحتوى قبل محاولة الإرسال أو عند رفضها. لا يُقبل نقل الشاهد إلى نوع رد آخر أو دمجه مع شاهد صلاحيات مختلف. تعديلات المجلدات لا تبطل ردود مكتبة الخاص غير المرتبطة بها. ردود المالك تحمل شاهد الإدارة من معاملة بناء الشاشة نفسها.

التخزين إضافة اختيارية communityFolders بحد ألف نطاق، مع رابط واحد لكل نطاق ومراجعة رقمية وحالة إتاحة. تُرفض السجلات المحرفة أو المتكررة أثناء القراءة والكتابة. تبقى الملفات القديمة دون الحقل صالحة، ولا تُنفذ أي هجرة أو تهيئة لقاعدة أصلية. أضيفت بنية URL والأزرار إلى المحول الأصلي للإرسال الخاص دون تمكين النشر إلى مجموعات أو قنوات.

الاختبارات على JSON وSQLite تغطي الحفظ والتأكيد والتعطيل، المدخل في الرئيسية والصفحات، الروابط العدائية، النسخ والتكرار والانتهاء والإلغاء، فقد الاعتماد وسحب التعليم، نتائج التحقق الثلاث واستثناء المالك، حجب الرد القديم، عزل المكتبة، تحقق شكل الشواهد ومحوها، وتسلسل URL وcallback عبر محول Bot API وهمي ومنع إعادة الإرسال. لا شبكة Telegram حقيقية أو بيانات أصلية في هذه الاختبارات.

الحدود: لا إنشاء أو مزامنة محتويات المجلد أو إثبات إضافته، ولا إدارة روابط دعوة المجموعات أو طلبات الانضمام أو CAPTCHA، ولا فحص نوع الجهة الحقيقي عبر getChat. إعداد الاشتراك منفصل صراحةً؛ لا يفعّل حفظ رابط قاعدة عددية جديدة بصمت، وتظهر إتاحة الرابط للطلاب فقط بعد تجهيز قاعدة صالحة. لا تُرسل أي رسالة تلقائيًا لطالب لم يبدأ الخاص. التحقق والظهور على عميل Telegram الحقيقي ما زالا يحتاجان القبول الحي.

تعطيل الإتاحة يمنع الاكتشاف والردود الجديدة والتحقق بالأزرار القديمة؛ لا يلغي رابطًا صادرًا من Telegram أو نسخة حفظها مستخدم، ولا يعطّل زر URL سبق إرساله. إلغاء رابط المجلد نفسه يتم من Telegram بواسطة مالكه. لم تُضف هذه الدفعة سجلًا لتحرير رسائل قديمة تلقائيًا؛ يبقى هذا ضمن BUTTON-014 ونطاق ربط المنشورات.
