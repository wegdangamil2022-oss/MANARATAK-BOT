# المرحلة الثانية — الشبكات المحلية المسمّاة

## نطاق هذه الدفعة

أصبح مسار «👥 المجموعات والشبكات ← 🌐 الشبكات والاتحادات» متصلًا بمحرر حقيقي **للتنظيم المحلي** للمالك في الخاص. يتيح إنشاء شبكة باسم قصير، ومعاينة الاسم وتأكيد الحفظ، وفتح الشبكة، ثم ربط المجموعات المعتمدة بها أو فصلها باستخدام معاينة وتأكيد مستقلين.

شبكات هذه الدفعة هي **تصنيفات تنظيمية داخل قاعدة بيانات البوت**؛ لا تنشئ اتحادًا في Telegram ولا تمنح صلاحيات نشر أو كتم أو حظر أو دعوات أو نقل رسائل بين المجموعات.

### نموذج التخزين

- الحقل الإضافي الاختياري `groupNetworks` في `BotState` (schema 8 بدون هجرة كاسرة) له حد أقصى **32 شبكة**. تُحفظ لكل شبكة هوية عشوائية واسم فريد وإصدار وتاريخ التعديل واسم المالك المنشئ وارتباطات المجموعات.
- أسماء الشبكات 2–48 حرفًا (حروف وأرقام ومسافات وشرطة وشرطة سفلية) بلا محارف تحكم أو وسوم HTML أو أسماء مكررة، وتُنسّق بصيغة NFC.
- لكل شبكة حتى **50 ارتباط مجموعة**. يخزّن الارتباط معرّف المجموعة وإصدار موافقتها عند الربط، لا نصوص الرسائل أو أسماء الطلاب أو مفاتيح Telegram.
- يُرفض أي سجل شبكة متعارض أو مكرر أو تالف في JSON وSQLite. لا تتم تهيئة الشبكات افتراضيًا من مجموعات موجودة، ولا تعتمد هوية مجموعة غير صالحة.

### التسلسل الآمن

1. يفتح المالك مسار الشبكات ويضغط «➕ إنشاء شبكة»، ثم يرسل اسمًا من خاص البوت. خطوة الاسم محددة بعشر دقائق، ولا تحفظ الشبكة قبل المعاينة.
2. معاينة الإنشاء تُصدر رمزًا خادميًا لمرة واحدة صالحًا لدقيقتين. عند التأكيد يفحص البوت الصلاحية والاسم والفهرس الحالي داخل معاملة ذرية؛ ويرفض الاسم المكرر أو تغير إعدادات المالك.
3. تفتح بطاقة الشبكة عدد الارتباطات **الفعالة** وعدد الارتباطات **التي تحتاج مراجعة**. يعد الارتباط فعالًا فقط إن ظلت المجموعة معتمدة وبالإصدار الذي رُبطت به. لا يُفسَّر السجل القديم على أنه اعتماد جديد.
4. تعرض «👥 إدارة المجموعات» صفحات من ثماني مجموعات معتمدة. يختار المالك مجموعة لإضافة الربط أو فصله، ويعاين الإجراء قبل التأكيد.
5. يربط التأكيد بهوية الشبكة وإصدارها، وإصدار المجموعة الحالي وموقعها في القائمة وبصمة حالة الاعتمادات وإعدادات المالك. يُرفض إذا تغير أحدها؛ وتبقى العملية منفصلة تمامًا عن إعدادات الحماية وحقوق Telegram.
6. زر «✖ إلغاء المعاينة» يبطل الرمز الخادمي، مع تسجيل الحفظ أو الإلغاء في سجل التدقيق المحلي. المحاولات المتزامنة لا تحفظ مرتين.

### القيود الباقية

- لا يوجد حتى الآن **إعادة تسمية الشبكات أو حذفها أو تنظيف ارتباطات المجموعات الملغاة** عبر الواجهة؛ يمكن عرض عدد الارتباطات التي تحتاج مراجعة فقط.
- لا توجد سياسات موحدة ذات أثر تنفيذي على الشبكات ولا دعوات Telegram ولا مزامنة عابرة للمجموعات.
- لا توجد هوية رسمية لشبكة على Telegram أو نسخ حقوق المجموعة الأم إلى المجموعات المتفرعة.
- اختبارات `tests/owner-inline-networks.test.ts` تراجع الإنشاء من النص الخاص والربط والفصل والأذونات وتبدل الإصدار والتزامن والإلغاء والفساد، على JSON وSQLite.

لذلك تبقى المرحلة الثانية ومطلب الشبكات والاتحادات مفتوحين، رغم توفر أساس تنظيمي قابل للاختبار.
