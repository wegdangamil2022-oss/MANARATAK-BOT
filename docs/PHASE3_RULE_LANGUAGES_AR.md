# لغات قوانين المجموعة الاختيارية

تنفيذ محلي للمطلب RULELAW-001؛ تجربة Telegram مؤجلة بطلب المستخدم، ولا يعلن هذا الملف إغلاق المرحلة الثالثة.

يحفظ كل إصدار النص الأساسي وتاريخ اعتماده وأرقام فقراته وحالة تعطيلها. يمكن للمخول إضافة حتى ثلاث ترجمات مراجعة يدويًا، لكل منها عدد الفقرات نفسه وبالترتيب نفسه. لا تُستدعى خدمة ترجمة ولا يستنتج البوت تهمة من النص المترجم.

في الخاص، أرسل مثلًا:

```
/translaterules -100 en
Respect members
No abuse
```

رمز اللغة حرفان صغيران، مع منطقة اختيارية من حرفين كبيرين مثل zh-CN. يسري حد النص الأساسي نفسه: 1–20 فقرة، حتى 120 حرفًا للفقرة وحد إجمالي للنص بعد تهريب HTML. تُرفض اللغة الرابعة أو اختلاف عدد الفقرات أو الحقول غير الموثوقة.

تعرض المعاينة نص اللغة المراد اعتمادها وتتيح التأكيد أو الإلغاء في الخاص. التأكيد خاص بالفاعل ولمدة دقيقتين ويعيد فحص التفويض وإصدار المجموعة وبصمة المصدر. ينشئ الاعتماد إصدارًا جديدًا، ويبقى التاريخ القديم دون تعديل. حذف لغة بواسطة `/removerulelang -100 en` يتطلب التأكيد نفسه، والإلغاء يبقيها منشورة.

يعرض `/rules` النص الأساسي داخل المجموعة، ويعرض `/rules en` أو `/rules@ManaratakBot en` اللغة المطلوبة إذا كانت معتمدة. لا يستبدل لغة مفقودة بنص آخر دون تصريح. تحمي بصمة الإصدار الردود المجهزة من إرسال ترجمة حُذفت أو تغيرت قبل التسليم.

تعطيل فقرة أو تفعيلها يحفظ الترجمات ويطبق حالتها على الرقم نفسه في كل لغة. تغيير النص الأساسي بواسطة `/setrules` يمسح ترجمات الإصدار السابق ويعرض النص الجديد كاملًا قبل التأكيد، لمنع ربط ترجمة قديمة بفقرات معدلة. تظل تفسيرات المخالفات القديمة مرتبطة بالنص الأساسي الأصلي وإصداره، ولا تُعاد كتابتها بعد الترجمة.

التحقق يشمل JSON وSQLite، المعاينة والتأكيد والإلغاء والتفويض والتعطيل وإعادة التفعيل والحذف وتلف التاريخ وتهريب HTML وحد الرسالة، والنقل عبر الخاص والمجموعة ومنع إرسال رد مترجم قديم. نتائج الاختبارات والسجل الشامل مثبتة في PHASE3_EXECUTION_STATUS_AR.md.
