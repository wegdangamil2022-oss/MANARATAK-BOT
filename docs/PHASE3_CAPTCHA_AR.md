# CAPTCHA — التحدي والإعدادات المحلية

نُفذ التحدي الفعلي بدل الوصف فقط: تُرصد أحداث انضمام الأعضاء البشرية في معالج Telegram، وتُنشأ جلسة مرتبطة بالعضو والمجموعة ونسخة اعتمادها وإعداداتها. المالك والمخول بإدارة المجموعة مستثنيان. لا تُرسل رسالة خاصة دون حدث من المستخدم؛ عند فتح الخاص بـ /start أو /captcha تظهر الجلسة، ومع تعدد المجموعات تظهر قائمة اختيار بصفحات.

يقدم المسار سؤال جمع عشوائيًا بثلاث إجابات وزر تحقق بديلًا يمكن الوصول إليه. المهلة قابلة للاختيار: 60 أو 120 أو 300 ثانية؛ المحاولات: 1 أو 3 أو 5. تُفصل المحاولات بثانيتين، وتسمح إعادة المحاولة بعد انتظار يتدرج بين الجولات، بحد ثلاث جولات ثم طلب مراجعة بشرية. لا يظهر زر إعادة تلقائي بعد الجولة الثالثة. هذا اختبار بسيط ولا يضمن إيقاف جميع الحسابات الآلية.

إعدادات المالك موصولة بالزر الرسمي «🤖 اختبار CAPTCHA» في قسم الانضمام: اختيار المجموعة، الإعداد، المعاينة، التأكيد المستقل، الإلغاء والرجوع. التنقل يلغي تأكيدًا ينتظر الحفظ، ويُرفض التأكيد عند تغير مصدر الصلاحية أو اعتماد المجموعة. تغيير الإعدادات يبطل الجلسة القديمة؛ انضمام جديد يستطيع إنشاء جلسة للنسخة الجديدة. يُحد عدد جلسات CAPTCHA المخزنة إلى ألف؛ تنظيف الجلسات القديمة ومراجعتها بحاجة إلى استكمال.

التحقق خاص بالعضو؛ لا يقبل زر عضو آخر. تُفحص عضويته من البوابة الحالية ويعاد فحص المصدر بعد الانتظار. التخزين JSON وSQLite يحفظ المشكلة والمهلة والمحاولات، ولا يعيد إصدار تحدي لمجرد تكرار الحدث خلال اليوم نفسه. الرجوع إلى الرئيسية متاح دون إجبار المستخدم على استكمال الاختبار في هذا الإصدار.

**حدود الإنجاز:** هذه نسخة اختبار دون فرض قيود. لم يوصل بعد منع الكتابة أو عقوبات CAPTCHA إلى Telegram، ولا موافقة القوانين وشرط الاشتراك ضمن رحلة واحدة، ولا صندوق مراجعة بشرية خاص بهذه الجلسات أو تنبيه تلقائي عند الانضمام. نجاح التحدي لا يفك أي عقوبة أو قيد اشتراك مستقل. تبقى VERIFY-002 وبقية التدرج العقابي والرحلة ذات الصلة مفتوحة؛ لا يُعد هذا إغلاق المرحلة الثالثة.

اجتاز البناء و70 اختبارًا محليًا: 20 لـ CAPTCHA وإعداداته ومسار التحديثات، و50 لفحص الحقوق وإدارة المشرفين ومراجعتها. شملت حالات الإلغاء أثناء التأكيد، والعضوية المفقودة وتغير المصدر، وتكرار الحدث، وانتهاء المهلة وإعادة المحاولة، واستنفاد المحاولات والتصعيد المحدود، وتعدد المجموعات، ورفض الجلسة المشوهة، واستمرار القيود المستقلة. سجل التحقق: artifacts/section-closure/captcha-focused-tests.log. يلزم قبول CI لهذه النسخة، ولا ينقل نجاح النسخة السابقة إليها.
