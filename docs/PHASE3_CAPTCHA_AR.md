# CAPTCHA — التحدي والإعدادات المحلية

نُفذ التحدي الفعلي بدل الوصف فقط: تُرصد أحداث انضمام الأعضاء البشرية في معالج Telegram، وتُنشأ جلسة مرتبطة بالعضو والمجموعة ونسخة اعتمادها وإعداداتها. المالك والمخول بإدارة المجموعة مستثنيان. لا تُرسل رسالة خاصة دون حدث من المستخدم؛ عند فتح الخاص بـ /start أو /captcha تظهر الجلسة، ومع تعدد المجموعات تظهر قائمة اختيار بصفحات.

يقدم المسار سؤال جمع عشوائيًا بثلاث إجابات وزر تحقق بديلًا يمكن الوصول إليه. المهلة قابلة للاختيار: 60 أو 120 أو 300 ثانية؛ المحاولات: 1 أو 3 أو 5. تُفصل المحاولات بثانيتين، وتسمح إعادة المحاولة بعد انتظار يتدرج بين الجولات، بحد ثلاث جولات ثم طلب مراجعة بشرية. لا يظهر زر إعادة تلقائي بعد الجولة الثالثة. هذا اختبار بسيط ولا يضمن إيقاف جميع الحسابات الآلية.

إعدادات المالك موصولة بالزرين الرسميين «🤖 اختبار CAPTCHA» و«⏳ المهل والمحاولات» في قسم الانضمام: اختيار المجموعة، الإعداد، المعاينة، التأكيد المستقل، الإلغاء والرجوع. التنقل يلغي تأكيدًا ينتظر الحفظ، ويُرفض التأكيد عند تغير مصدر الصلاحية أو اعتماد المجموعة. تغيير الإعدادات يبطل أزرار الجلسة القديمة؛ يستطيع العضو فتح الخاص لإنشاء تحدٍ للنسخة الحالية بعد فحص عضويته، دون الحاجة إلى المغادرة وإعادة الانضمام. يُحد عدد جلسات CAPTCHA المخزنة إلى ألف؛ يُنظّف الآن تلقائيًا عند استقبال انضمام جديد ما يصل إلى 100 جلسة ناجحة مضى على إصدارها يوم، بعد مطابقة إيصال النجاح. تبقى الجلسات الفاشلة وغير المحسومة أو المرتبطة بأي سبب أو عملية عقابية محفوظة للمراجعة؛ تنظيفها ومراجعتها بحاجة إلى استكمال.

التحقق خاص بالعضو؛ لا يقبل زر عضو آخر. تُفحص عضويته من البوابة الحالية ويعاد فحص المصدر بعد الانتظار. التخزين JSON وSQLite يحفظ المشكلة والمهلة والمحاولات، ولا يعيد إصدار تحدي لمجرد تكرار الحدث خلال اليوم نفسه. الرجوع إلى الرئيسية متاح دون إجبار المستخدم على استكمال الاختبار في هذا الإصدار.

**حدود الإنجاز:** هذه نسخة اختبار دون فرض قيود. لم يوصل بعد منع الكتابة أو عقوبات CAPTCHA إلى Telegram، ولا موافقة القوانين وشرط الاشتراك ضمن رحلة واحدة، ولا قرارات قبول ورفض بشرية خاصة بهذه الجلسات أو تنبيه تلقائي عند الانضمام. نجاح التحدي لا يفك أي عقوبة أو قيد اشتراك مستقل. تبقى VERIFY-002 وبقية التدرج العقابي والرحلة ذات الصلة مفتوحة؛ لا يُعد هذا إغلاق المرحلة الثالثة.

## تنظيف الجلسات الناجحة

ينفذ التنظيف داخل المعاملة نفسها قبل تطبيق حد الألف عند رصد انضمام موثوق. لا يحذف سجل النجاح، ولا أي سبب أو عملية عقابية. تُرفض الجلسات المشوهة أو ذات الإيصال المفقود أو المكرر أو المعدل، ولا يعاد إصدار تحدٍ للناجح خلال أول يوم. الحد 100 حذف في الاستدعاء؛ لا يوجد حذف شامل للجلسات الفاشلة أو التي قد تحمل دليل إنفاذ. اجتاز البناء و28 اختبار CAPTCHA على JSON وSQLite بعد هذا التعديل؛ نتيجة Ubuntu السابقة أعلاه تخص مصدرها المسجل ولا تشمل هذا التعديل حتى إعادة CI.

## عرض حالات المراجعة

من إعداد CAPTCHA يستطيع المالك فتح «مراجعة الحالات»: قائمة بصفحات من ثماني حالات، ثم تفاصيل العضو والمجموعة والجولة والمحاولات ونهاية المهلة، مع الرجوع للقائمة والإعدادات وقسم الانضمام. تظهر فقط جلسات الجولة الثالثة التي فشلت أو انتهت مهلتها، بعد تحقق بنيتها واعتماد المجموعة؛ يعاد فحص الحالة عند الضغط. الأزرار قصيرة العمر ومخصصة للمالك وتستهلك مرة واحدة. يُربط دليل عرض لوحة المالك بجلسات CAPTCHA لمنع إرسال تفاصيل مؤجلة بعد تغيرها. هذا عرض للمراجعة ولا يتضمن بعد قرار قبول أو رفض بشري أو فك قيد. اجتاز البناء و80 اختبارًا مركزًا محليًا بعد الإضافة: 30 لـ CAPTCHA و50 لإدارة المشرفين وفحص الحقوق.

## قرارات المراجعة البشرية

أصبحت قائمة المالك تتضمن قبول التحقق أو رفضه: تفاصيل الحالة، معاينة الأثر، تأكيد مستقل، إلغاء ورجوع. يُحفظ قرار وحيد دائم مرتبط ببصمة الجلسة ونسخة اعتماد المجموعة. يُلغى التأكيد عند تغيير الجلسة أو إعداداتها أو أسباب وعمليات القيود، وعند انتهاء الدقيقتين أو التنقل حتى أثناء انتظار الحفظ. القرار يخص CAPTCHA وحده؛ لا يرفع عقوبة أو قيد اشتراك ولا يمنح موافقة القوانين. تظهر النتيجة للعضو عند فتح الخاص بعد فحص عضويته، دون إرسال خاص تلقائي.
